# Causal Inference in R（中文译本）

《Causal Inference in R》是 Kamran Afzali 撰写的因果推断在线书（bookdown，2026-01-17）的**中文译本**，全书 14 章一次译完。

在线阅读：**https://zhangkaicr.github.io/causal-inference-r-cn/**

## 本书讲什么

原书以医疗健康研究为应用场景，用 R 语言贯通从经典识别设计到现代机器学习的完整方法谱系：

| 章 | 标题 | 一句话定位 |
|---|---|---|
| 1 | 因果统计分析基础 | 全书地图：术语、假设与技术总表 |
| 2 | 随机对照试验与回归调整 | 为什么随机化是金标准，回归调整在其中的位置 |
| 3 | 倾向得分、双稳健估计量与逆概率加权 | 观察性数据的去混杂主力工具 |
| 4 | 双重差分及其医疗应用 | 政策评估的准实验设计，平行趋势与安慰剂检验 |
| 5 | 工具变量 | 未观测混杂的绕道路径，LATE 与排他性约束 |
| 6 | 断点回归设计 | 阈值附近的「准随机化」，带宽与精确/模糊断点 |
| 7 | 因果森林 | 用随机森林估计个体处理效应，诚实推断 |
| 8 | 用于因果推断的贝叶斯结构时间序列 | 合成控制与政策干预前后的时序评估 |
| 9 | 面向异质处理效应的元学习器 | S/T/X/R-learner 的分工与取舍 |
| 10 | 面向医疗稳健因果推断的靶向极大似然估计 | TMLE：双稳健 + 半参数效率 |
| 11 | 用于因果推断的 g-计算 | 标准化与纵向数据、时依混杂 |
| 12 | 医疗研究中的结构方程模型 | 路径分析、潜变量与复杂因果通路 |
| 13 | 有向无环图 | 用因果图指导变量选择，后门准则与碰撞因子 |
| 14 | 双重机器学习 | Neyman 正交 + 交叉拟合，容忍机器学习的偏差 |

## 译本特点

- **完整翻译**：14 章全部译出，章节、代码、公式、图表、表格无一省略
- **代码注释中文化**：R 函数名与参数名保留英文，注释译为中文；控制台输出保留英文原文并附中文解读，教读者该看什么
- **「背景与解释」框**：在关键概念处补充面向医学研究者的铺垫——这个概念在流行病学里对应什么、临床研究里为什么重要、常见误区是什么。共 100+ 个说明框
- **公式可渲染**：LaTeX 公式原样保留，由 MathJax 渲染
- **明暗主题**：右上角圆形按钮或 Alt+T 切换，偏好跨页保持
- **离线自足**：图片与样式均无需本地依赖（公式渲染需联网加载 MathJax）

## 本地构建

译文正文片段存放在构建目录 `chapters/*.frag.html`，由 `_tools/build_book.py` 套入统一模板生成 `chapters/*.html` 与 `index.html`：

```bash
python _tools/build_book.py          # 片段 -> 页面
python _tools/verify_frag.py         # 逐章校验（代码块/图片/公式/标签平衡）
```
