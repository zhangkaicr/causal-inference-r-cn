12.1 引言

假设你正在评估一项新的糖尿病预防项目对患者结局的影响。该项目包含营养教育、运动咨询和压力管理三个组成部分。你观察到，六个月后参与者的血糖控制有所改善，但其作用机制仍不清楚。该项目主要通过改变饮食行为起效吗？运动是否扮演主导角色？减压之类的心理因素是否中介了身体健康方面的获益？回答这些问题，需要理解的不只是「干预是否有效」，而是它如何通过生物、行为与心理机制相互关联的通路起作用。

传统回归分析难以应对这种复杂性，因为它孤立地处理每一对关系，忽略了真实世界健康过程所特有的、由直接效应与间接效应交织成的复杂网络。我们不能简单地把结局同时对所有潜在中介变量做回归，而不考虑它们的相互依赖性、自报行为中的测量误差，以及那些只能通过多个不完美指标间接观测的潜在心理构念。

结构方程模型（Structural Equation Modeling, SEM）提供了一个统一框架来应对这些挑战：它同时估计多个回归方程，并显式地对测量误差和不可观测的潜在构念建模。与逐条通路分别分析的「分段回归」做法不同，SEM 把整个因果系统当作一个相互关联的整体，给出所有直接效应与间接效应的内在一致估计，同时让不确定性恰当地贯穿复杂的中介链传播。

这种方法的力量在于，它能用观测数据检验特定的理论模型，从而在「干预如何产生效应」的多种竞争性解释之间作出甄别。就糖尿病预防项目而言，SEM 可以量化饮食改变与运动增加的相对重要性，估计总效应中有多大比例通过减压实现，并检验心理健康是否中介了行为改变与代谢结局之间的关系。这些机制性洞察把项目评估从简单的效力评估，转变为「哪些项目组分值得重点投入、哪些人群最适合特定干预策略」的可操作指导。

SEM 融合了两个互补的建模框架，分别应对因果推断中的不同挑战。测量模型（measurement model）把不可观测的潜在构念与其可观测指标连接起来，显式处理会令传统回归估计产生偏倚的测量误差。结构模型（structural model）则规定变量间的因果关系，既包括已观测的特征，也包括来自测量模型的潜在构念。这种整合使研究者能够检验关于「心理构念、行为模式与健康结局如何互联」的复杂理论，同时承认我们的测量只是对所关心构念的不完美捕捉。

以测量心血管病患者的抑郁严重程度为例。没有任何单一问题能完美捕捉「抑郁」这个多面构念，因此我们使用贝克抑郁量表（Beck Depression Inventory）这类工具，用多个条目评估情绪、精力、睡眠和认知。每个条目都提供关于潜在抑郁的噪声信号，既包含潜在构念的真实信息，也包含条目特有的测量误差。测量模型通过因子分析把这种关系形式化：假定个体 \(i\) 在条目 \(j\) 上的观测得分 \(Y_{ij}\) 服从 \(Y_{ij} = \lambda_j \eta_i + \epsilon_{ij}\) 的结构，其中 \(\eta_i\) 代表个体 \(i\) 真实但不可观测的抑郁水平，\(\lambda_j\) 度量条目 \(j\) 在抑郁因子上的载荷强度，\(\epsilon_{ij}\) 捕捉该个体与该条目特有的测量误差。

结构模型则通过联立方程组把潜在构念与观测变量联系起来。对心血管病患者，我们可以假设体力活动 \(X\) 降低抑郁 \(\eta_1\)，抑郁进而影响服药依从性 \(\eta_2\)，最终影响临床结局 \(Y\)。结构方程把这些关系形式化为 \(\eta_1 = \gamma_1 X + \zeta_1\)、\(\eta_2 = \beta_{21} \eta_1 + \gamma_2 X + \zeta_2\) 和 \(Y = \beta_Y \eta_2 + \gamma_Y X + \epsilon_Y\)，其中希腊字母代表因果效应，误差项 \(\zeta\) 和 \(\epsilon\) 捕捉各环节无法解释的变异。

这一联立方程组体系是 SEM 区别于「序贯回归」的关键。当我们估计抑郁对依从性的效应时，SEM 会自动考虑「我们此前用同一批数据估计了抑郁的决定因素」这一事实，对这种相互依赖性恰当地调整标准误和参数估计。该方法让不确定性贯穿整个因果链传播——因为我们对早期关系的认识不完美，必然影响下游效应估计的精度。

背景与解释

临床研究者读到这里最自然的疑问是：SEM 和本书前面讲的 DAG（有向无环图）是什么关系？简单说，SEM 的路径图就是 DAG 的一种「带参数的化身」：DAG 用箭头表达定性因果假设（谁影响谁），SEM 在同样的箭头上标注待估的回归系数、残差协方差与因子载荷，并假定这些关系大多是线性的、误差是正态的。DAG 关心「哪些路径需要阻断才能识别因果效应」（后门准则），SEM 关心「给每条路径一个数值」。因此在报告顺序上，正确做法是先用 DAG 把混杂结构想清楚，再把 DAG 翻译成 SEM 的路径图——跳过 DAG 直接拟合 SEM，很容易把「相关结构拟合得好」误当成「因果假设成立」。

SEM 的因果解释依赖于强有力的结构假设，研究者必须通过理论与设计来论证其合理性。该方法假定我们已经正确规定了所有相关因果关系，且没有遗漏所建模关系的重要混杂因子。这一要求远比简单回归苛刻，因为 SEM 模型通常包含多个内生变量，而它们彼此之间的关系也可能受到混杂。以抑郁影响依从性为例，我们必须假设：在条件于已纳入协变量后，没有未测量变量同时影响这两个构念——随着模型日益复杂，这一假设越来越难以成立。

识别问题（identification problem）问的是：变量间观测到的协方差结构是否包含足够的信息，来唯一确定所有模型参数。当每个参数都对应一个能复现观测协方差的唯一解时，模型是可识别的（identified）。不可识别（underidentified）的模型容许无穷多组与数据一致的参数值，若无额外约束则无法估计。过度识别（overidentified）的模型施加了超出必要数量的约束，可以利用多余信息通过拟合优度统计量检验模型拟合。

识别需要对模型结构与尺度设定格外小心。潜在变量没有固有尺度，因此我们必须通过两种方式之一为其锚定：把某个因子载荷固定为 1，或把潜在变量的方差标准化。在递归模型（recursive，所有因果效应单向流动、无反馈环）中，识别通常比非递归模型（非递归，含双向关系，需要工具变量或其他排他性约束）更容易实现。

背景与解释

路径分析（path analysis）与潜变量模型（latent variable model）常被混为一谈，其实它们是 SEM 的两个特例：只含观测变量、不含潜在构念的 SEM 就是路径分析（心理学里 Wright 1920 年代的开创性工作）；引入因子与指标的才是完整的潜变量 SEM。临床研究中两者的取舍很实际：如果所有变量都是客观测量（血压、HbA1c、给药剂量），路径分析足够；如果涉及量表（如 SF-36、PHQ-9、生活质量评分），潜变量模型能把「真实构念」与「条目噪声」分离，估计出的构念间效应偏差更小——代价是样本量要求更高（粗略经验是每个自由参数至少 5–10 个观测），且识别问题更棘手。很多医学论文用「验证性因子分析 + 路径分析」两步走，正是出于这种务实考虑。

路径图为理解识别提供了极宝贵的直觉：它把因果关系可视化为从原因指向结果的箭头。没有入箭头的变量是外生变量（exogenous），其变异来自模型系统之外；有入箭头的是内生变量（endogenous），部分地由其他模型变量解释。弯曲的双向箭头表示变量间的协方差，而不断言因果方向。这种图形表示让模型假设透明化，并帮助识别威胁因果解释的潜在混杂或遗漏变量问题。

12.2 一项中介分析：体力活动、心理健康与糖尿病控制

背景与解释

这段模拟代码本身就是理解 SEM 因果假设的最佳教材。注意三个潜在构念（exercise_level、depression、adherence）在生成数据时是「真实存在」的连续变量，但 SEM 分析时看不到它们——只能看到 10 个带噪声的条目。这正是临床量表的日常处境：我们想推断「抑郁」「依从性」这些构念，手里却只有问卷作答。模拟还刻意让结局依赖于多个中介，因此粗看干预组 HbA1c 平均变化 0.644 小于对照组 0.925（差值约 -0.28，负值代表改善），但这个差值混合了直接效应、间接效应和基线 baseline_hba1c 的残余关联，必须靠模型分解。另一个关键点：干预是随机化的，所以「干预 → 中介」无混杂；但中介之间的路径（如抑郁 → 依从性）仍是观察性的，需要协变量调整——这一区别是后面所有中介解释的前提。

我们模拟的数据集代表一项运动干预的随机试验，纳入 800 名 2 型糖尿病患者。干预分配是随机的，这满足了最强的识别假设——保证干预的因果效应不受混杂影响。然而，中介变量——运动参与、抑郁与依从性——仍是观察性的，需要仔细建模它们的相互关系及潜在混杂因子。

# 设定结构方程模型
sem_model <- '
  # 测量模型：由指标定义潜在构念
  depression =~ dep_mood + dep_energy + dep_sleep + dep_worth
  exercise =~ ex_frequency + ex_duration + ex_intensity
  adherence =~ adh_medication + adh_monitoring + adh_diet
  
  # 结构模型：因果关系
  exercise ~ b1*intervention + age + bmi
  depression ~ b2*exercise + b3*intervention + bmi + baseline_hba1c
  adherence ~ b4*depression + b5*exercise + b6*intervention
  hba1c_change ~ b7*exercise + b8*depression + b9*adherence + 
                 b10*intervention + baseline_hba1c
  
  # 定义用于中介分析的间接效应
  indirect_ex_dep := b2 * b8
  indirect_ex_adh := b5 * b9
  indirect_ex_dep_adh := b2 * b4 * b9
  indirect_dep_adh := b4 * b9
  
  # 通过所有中介的总间接效应
  total_indirect := b2*b8 + b5*b9 + b2*b4*b9 + (b2*b4 + b3)*b9 + b3*b8
  
  # 干预的总效应
  total_effect := b10 + total_indirect
'

# 用极大似然估计拟合模型
sem_fit <- sem(sem_model, data = sem_data,

模型设定明确区分了测量部分与结构部分。在测量模型中，我们用 =~ 运算符（读作「由……测量」）从各自指标定义三个潜在构念。每个构念的第一个载荷是自由估计的，而非固定为 1，这让数据自行决定哪个指标最强地反映其潜在构念。结构模型使用带 ~ 运算符的标准回归语法来规定有向因果路径。我们用 b1、b2 等记号标注关键参数，以便后续计算间接效应。

:= 运算符把新参数定义为已估参数的函数，从而通过直接效应的组合实现中介分析。例如 indirect_ex_dep := b2 * b8 捕捉「干预通过提高运动水平、进而降低抑郁、最终改善血糖控制」这条通路贡献了多少效应。这些间接效应是特定因果链上路径系数的乘积，其标准误通过 delta 方法计算，以计入每个组成部分的不确定性。

背景与解释

直接效应、间接效应与总效应的关系是：总效应 = 直接效应 + 各间接效应之和。在本例中，干预的总效应 total_effect = -0.113（HbA1c 下降 0.113），其中直接通路 b10 = -0.077，其余约 -0.036 经由中介传递。读这类结果时要记住两个「但是」：第一，间接效应的符号和大小依赖于线性、无交互假设——若干预与抑郁对依从性有交互，间接效应就不再是简单乘积；第二，SEM 估计的间接效应是「效应分解」意义上的，其因果解释要求中介–结局关系无未测混杂（12.3 节会展开）。另外，原书的 total_indirect 写法把所有中介链手工相加，路径一多就容易漏项，实践中更推荐用 lavaan 的 fitted() 或 lavaan::lavInspect(fit, "symmetric") 自动枚举全部有向路径，避免代数错误。

背景与解释

拟合指数是 SEM 论文的「标配展台」，但误读极多。要点有四：（1）卡方检验的是精确拟合——模型隐含的协方差与样本协方差是否完全一致；样本量越大，越容易把微不足道的偏差判成「显著」，所以卡方显著不等于模型没用，Hu 和 Bentler 1999 之后学界通行「卡方 + 近似指数」联合判读。（2）CFI/TLI 是「与最差模型比较的相对改进」，> 0.95 算好，0.9–0.95 算可接受；TLI 对模型简约性有惩罚。（3）RMSEA 是「每自由度平均失配」，< 0.05 紧密、< 0.08 可接受，且一定要报告其置信区间——若区间上界越过 0.1，模型就不可信。（4）SRMR 是标准化残差相关的均值，< 0.08 为佳。反过来要强调：拟合好只证明「模型没有明显被数据拒绝」，不证明因果关系正确——一个因果方向完全画错的模型照样可以拟合得很好。医学期刊审稿人越来越要求同时报告以上四类指数，缺项的 SEM 论文常被直接退稿。

模型拟合评估考察的是：我们的理论结构是否充分复现了数据中观测到的协方差模式。卡方检验提供精确拟合的总量检验，但在大样本中，即使拟合良好的模型也常被拒绝——因为微不足道的偏差也能达到统计显著。更务实的拟合指数包括比较拟合指数（CFI）与 Tucker-Lewis 指数（TLI），它们把我们的模型与「假定变量间毫无关系」的基线模型相比较，取值超过 0.95 表示拟合良好。近似误差均方根（RMSEA）按自由度量化观测协方差与模型隐含协方差之间的平均差异，取值低于 0.06 提示紧密拟合。标准化均方根残差（SRMR）度量平均绝对相关残差，低于 0.08 被认为可接受。

背景与解释

「中介比例」（proportion mediated）是医学论文里最常被误用的统计量之一。它等于总间接效应除以总效应，直觉是「干预的获益有多大比例走中介通路」。问题在于：（1）当直接效应与间接效应符号相反或总效应接近 0 时，该比例可以大于 1 或为负，毫无解释价值；（2）它隐含「效应可加性」，非线性/交互存在时分解不唯一；（3）现代因果中介框架（VanderWeele、Robins 等）更推荐报告自然直接效应与自然间接效应及其比例，而非线性 SEM 的路径乘积。Baron-Kenny（1986）的经典四步法在教材中仍常见，但它对中介效应的检验效能低、且第一步「X 显著预测 M」并非必要条件——综述与方法学论文（如 Imai et al. 2010）已多次纠偏。报告时，请同时给出未标准化的间接效应、其置信区间（bootstrap 优先），以及中介比例（若计算）及其不适用的情形说明。

中介分析把干预效应分解为若干组成通路，量化每条机制贡献了多少获益。我们区分经由单一中介的简单间接效应与经由多个序贯中介的复合效应。例如，「干预 → 运动 → 抑郁 → 依从性 → 血糖控制」是一条三步中介链，每一环的强度决定整条通路的量级。中介比例指示总干预效应中有多大比例经由已测中介通路传递，而非通过直接生物效应或未测量机制实现。

测量模型的效度决定我们的潜在构念能否有意义地代表其拟捕捉的心理与行为现象。因子载荷指示每个指标反映其底层构念的强度，标准化载荷大于 0.5 视为可接受，大于 0.7 表示强关系。弱载荷提示指标对其拟测构念的测量不佳，可能反映测量误差、构念歧义，或条目捕捉了多个潜在因子的多维性。

模型的「自由度」与「简约性」值得一说：本例完整模型 74 个自由度，源于 15 个观测变量共有 120 个协方差元素，模型只估 46 个参数。受限模型多 1 个自由度却几乎不改善卡方，说明直接效应参数「性价比」太低——这是模型比较的典型逻辑（用 AIC/BIC 权衡拟合与复杂度）。但临床研究者要警惕一种陷阱：用拟合指数做「模型搜素」——不断删路径直到拟合最好，然后宣称「数据支持该理论」。这种做法等于把模型选择权交给噪声，正确姿势是让理论先验决定结构，用拟合与敏感性分析做事后检验。此外，lavaan 的 anova() 对嵌套模型自动做卡方差异检验，但两个模型若测量部分不同则不适用。

# 评估测量模型质量
reliability_analysis <- function(fit, factor_name) {
  # 提取该因子的载荷
  params <- parameterEstimates(fit, standardized = TRUE)
  loadings <- params[params$op == "=~" & params$lhs == factor_name, "std.all"]
  
  # 计算组合信度（Omega）
  sum_loadings <- sum(loadings)
  sum_squared_loadings <- sum(loadings^2)
  
  # 提取误差方差
  indicator_names <- params[params$op == "=~" & 
                            params$lhs == factor_name, "rhs"]
  error_vars <- sapply(indicator_names, function(ind) {
    1 - params[params$lhs == ind & params$op == "~~" & 
               params$rhs == ind, "std.all"]^2
  })
  sum_error_vars <- sum(error_vars)
  
  omega <- sum_squared_loadings / (sum_squared_loadings + sum_error_vars)
  
  # 平均方差提取量
  ave <- sum_squared_loadings / length(loadings)
  
  return(list(
    omega = omega,
    ave = ave,
    loadings = loadings,
    n_items = length(loadings)
  ))
}

这段输出里有个值得玩味的现象：三个因子的标准化载荷都不低（0.54–0.82），按 Fornell-Larcker 判据 AVE 也多数达标，但 Omega 全部低于 0.7。细看这段自定义 reliability_analysis()，能发现两处口径问题：其一，Omega 的分子应为载荷和的平方 \((\sum\lambda_j)^2\)，代码里的 sum_squared_loadings 用的却是载荷平方和 \(\sum\lambda_j^2\)——后者其实是 AVE 的分子；其二，误差方差一项又把标准化误差方差平方了一次（\(1-(1-\lambda_j^2)^2\)），进一步扭曲了分母。按正确公式重算，抑郁因子的 Omega 约为 0.80，其实完全达标。这提醒我们：论文里报告信度系数前，务必核对公式口径——Cronbach's α、组合信度（Omega）、AVE 三者分子分母各异，自己写的函数或软件默认选项都可能与教科书公式不一致。AVE 低于 0.5（如本例的依从性 0.359）意味着条目方差中过半来自误差，该构念上的结构路径估计会衰减（attenuation），解释效应大小时要相应保守。

组合信度（系数 omega）通过比较指标集合中「真实分数方差」与「总观测方差」来量化内部一致性。取值超过 0.7 表示各指标一致地测量同一底层构念，信度可接受。平均方差提取量（AVE）表示指标方差中被潜在因子捕捉（相对于测量误差）的比例，超过 0.5 表示大部分方差反映构念而非噪声。

这些指标验证我们的多条目量表捕捉到的是连贯的潜在构念，而非关系松散的变量的随意堆砌。强测量模型增强「结构关系反映真实因果过程而非测量假象」的信心。当信度不足时，研究者应考虑剔除弱指标、补充测量工具，或重新概念化构念以更好地匹配可观测现象。

12.3 临床解读与局限性

结构方程模型揭示，运动干预通过多个相互关联的机制（而非单一主导通路）降低 HbA1c。总干预效应中约 60% 经由已测中介传递——体力活动增加、抑郁症状减轻、治疗依从性改善——其余 40% 代表直接生物效应或未测量机制，如胰岛素敏感性改善与炎症调节。

最强的通路是「运动减轻抑郁，进而增强服药依从性，最终改善血糖控制」。这条三步中介链对总效应的贡献远超运动对代谢的直接效应，凸显了心理机制在糖尿病管理干预中的关键角色。未能经历抑郁减轻的患者，即使体力活动成功增加，干预获益也会打折——这提示：筛查难治性抑郁并提供辅助心理健康支持，或许能提升项目效果。

这些机制性洞察通过识别「微小改进即可产生级联收益」的杠杆点来改造干预设计。投入抑郁管理的资源可能比等量投入运动促进产生更大的整体效应，因为抑郁减轻会触发多种健康行为的连锁改善。模型还提示治疗反应的异质性：基线抑郁更严重的患者有更大的心理改善空间，因此若运动干预成功减轻其抑郁症状，整体获益可能更大。

在临床落地中应用这些结论，需要仔细考量因果解释背后的假设。虽然干预随机化保证了其对中介的效应无混杂，但中介–结局关系仍是观察性的、可能受混杂。未测量因素——如健康素养、社会支持或遗传倾向——可能同时影响抑郁与依从性，令中介效应估计产生偏倚。量化「多强的未测混杂才能推翻结论」的敏感性分析能提供一定安慰，但无法根除这些疑虑。

背景与解释

为什么「干预随机化」救不了中介分析？画个 DAG 就清楚了：随机化只切断了指向干预 \(D\) 的混杂箭头；但中介 \(M\) 与结局 \(Y\) 之间若存在共同原因 \(U\)（如健康素养 \(U\) → 依从性 \(M\)，\(U\) → HbA1c \(Y\)），SEM 估计的 b4、b9 就混入了 \(U\) 的效应。这就是为什么近年方法学界（如 VanderWeele 2015；Bulbulia et al.）反复强调：中介分析必须假设「中介–结局无未测混杂」，这与观察性研究的可忽略性是同一族假设，一点也不弱。可行的加固手段包括：（1）测到并调整尽可能多的中介–结局共同原因（本例中的 BMI、基线 HbA1c 就是范例）；（2）敏感性分析/E 值评估未测混杂的威胁程度；（3）设计上采用「干预–中介」随机化（若伦理可行，如随机分配运动课程以随机化中介）；（4）对中介–结局关系使用工具变量或前门准则。请记住：没有这些加固，「中介效应显著」只能读作「与理论一致的条件关联」，不能读作「机制被证实」。

结构方程模型继承了其强参数化与强结构假设的根本局限，实践者必须对此有清醒认识。线性假设把关系限制为沿直线的加性效应，可能错过阈值效应（干预仅在超过某剂量水平后才起效）或倒 U 型关系（适度运动的收益超过久坐与极端训练两者）。广义 SEM 扩展可容纳非线性关系与非正态结局，但需要更大样本与更复杂的设定。

「结构关系无未测混杂」的假设，也许是观察性中介分析中因果有效性面临的最严重威胁。虽然随机分配干预保证了处理效应无混杂，中介–结局关系仍易受「制造虚假关联」的隐藏因素影响。嵌入 SEM 框架内的工具变量方法有时能在排他性约束成立时放松这些假设，但在实践中找到有效工具变量依然困难。

测量模型假设要求指标只反映单一潜在构念，不在多个因子上交叉载荷（cross-loading）。真实心理测量工具常常违反这一假设——个体条目捕捉的是复杂现象的多重侧面。探索性结构方程模型（ESEM）允许交叉载荷，同时保留同时估计的优势，以额外参数和复杂度为代价，给出更现实的测量结构。

该方法还假定模型设定正确，包括所有相关通路、不遗漏重要变量。误设会使参数估计与标准误产生偏倚，并制造误导性的拟合统计量——让模型看似充分，实则根本上有缺陷。理论根基、审慎的协变量选择、跨多个数据集的验证有助于缓解这些风险，但无法完全消除。

最新进展把经典 SEM 扩展到日益复杂的场景：建模时间变化的纵向设计、考虑医疗机构或地理区域聚类的多水平模型、以及识别具有不同因果结构的潜在亚组的混合模型。这些扩展使机制如何跨人群与情境变化的研究更为细致，支持建立在个体水平因果过程的机制性理解之上的真正个性化医疗。

12.4 结论

结构方程模型为解开「医疗干预影响患者结局的复杂因果通路」提供了强大工具。通过同时建模测量误差与结构关系、并量化直接与间接效应，SEM 超越了简单的效力估计，走向为干预优化与个性化提供信息的机制性理解。我们的糖尿病预防分析展示了该方法如何揭示：抑郁减轻等心理机制对干预获益的贡献，往往大于临床研究通常强调的直接生物效应。

该框架把测量模型与结构模型整合在一起，应对了健康研究中的根本挑战——像生活质量、患者参与度或治疗负担这类关心构念无法被直接观测，只能从多个不完美指标推断。通过显式建模这一测量过程，SEM 给出偏倚更小的因果效应估计，同时恰当地量化不确定性。由此得到的机制性洞察使研究者能够识别：哪些干预组分值得重点投入，哪些患者亚组最可能从针对性的项目修改中获益。

成功的应用需要对理论设定、识别条件以及因果解释背后的强假设给予审慎关注。当该方法由关于因果机制的实质理论引导、由具有既定效度的高质量测量工具支撑、并通过评估对假设违反稳健性的敏感性分析验证时，效果最佳。在这些条件成立时，SEM 把临床研究从黑箱式的效力评估，转变为加速开发更有效、更高效、更公平的医疗干预的机制性理解——这些干预可量身定制于不同患者群体的复杂需求。
