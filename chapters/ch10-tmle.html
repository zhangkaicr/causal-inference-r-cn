第 10 章 面向医疗稳健因果推断的靶向极大似然估计

原书第 10 章 · targeted-maximum-likelihood-estimation-for-robust-causal-inference-in-healthcare.html · Kamran Afzali《Causal Inference in R》中文译本 · 非官方翻译

10.1 引言

设想你正在分析电子健康档案（EHR），想判断一种新型降压药与标准治疗相比能否减少心血管事件。与随机试验的受控环境不同，观察性数据带来了复杂的挑战：接受新药的患者可能与接受标准治疗的患者存在系统性差异，治疗决策取决于无法测量的医生偏好，而电子健康档案中还包含缺失数据和测量误差——这些都可能使传统分析产生偏倚。

这个场景集中体现了观察性因果推断的根本张力：是做出可能错误的强参数假设，还是采用可能低效或不稳定的灵活非参数方法。传统回归模型假设我们已经知道患者特征与治疗分配、结局之间正确的函数形式——在复杂的医疗环境中，这种假设很少站得住脚。反过来，纯粹的非参数方法在患者特征众多而复杂时，又会遭受维度灾难。

靶向极大似然估计（TMLE）通过一个有原则的框架化解了这一两难：它把机器学习的灵活性与半参数效率理论的统计严谨性结合起来。常规方法要求人们在「参数效率」与「非参数稳健性」之间二选一，而 TMLE 提供了双稳健性（double robustness）——只要治疗分配模型或结局模型中有一个设定正确（不必两者都对），因果估计就有效。

双稳健性彻底改变了观察性研究：它承认我们无法完美建模复杂的医疗过程，却仍能在模型大致正确时给出统计上最优的估计。TMLE 通过靶向偏倚校正实现这一点——它专门优化模型中与目标因果参数最相关的部分，而不是试图以同等精度对数据生成过程的每个侧面都建模。

TMLE 诞生于半参数效率理论。该理论为「数据生成过程某些侧面已知、其余侧面不设定」时的最优估计提供了数学基础。在因果推断场景中，我们通常知道因果问题的结构——例如要估计平均处理效应 \(\mathbb{E}[Y^1 - Y^0]\)——但不清楚患者特征、治疗分配与结局之间复杂的关系。

根本的洞见在于：像平均处理效应这样的因果参数，可以表示为数据生成分布 \(P_0\) 的泛函，记作 \(\Psi(P_0)\)。对于平均处理效应，它写成 \(\Psi(P_0) = \mathbb{E}_{P_0}[\mathbb{E}_{P_0}[Y|A=1,W] - \mathbb{E}_{P_0}[Y|A=0,W]]\)，其中 \(W\) 代表患者特征，\(A\) 表示治疗分配，\(Y\) 表示结局。这一表述把「想估计的因果参数」与「沿途必须处理的扰动函数（nuisance function，即干扰参数）」——结局回归 \(\mathbb{E}[Y|A,W]\) 与倾向得分 \(\mathbb{E}[A|W]\)——清晰地分离开来。

效率下界定理（efficiency bound theorem）表明：任何 \(\Psi(P_0)\) 的正则且渐近线性的估计量，其渐近方差都有一个下界 \(\text{Var}(D^*(O))\)，其中 \(D^*(O)\) 是该参数的有效影响函数（efficient influence function）。影响函数刻画了每个观测对参数估计的贡献，也是最优表现的理论基准。

背景与解释

TMLE 的名字值得拆开理解。Targeted（靶向）指的是：算法的最后一步不是继续改善对数据分布的拟合，而是朝着目标参数做一次定向修正——只优化与待估因果量相关的那个方向。可以类比临床检验中的「校准」：常规回归优化的是整体预测误差（相当于把仪器整体调准），而 TMLE 只针对你要报告的那个指标（血压？糖化血红蛋白？）做定向补偿。Maximum Likelihood Estimation（极大似然）则说明它仍以似然为骨架：先在似然框架下用机器学习估计初始模型，再沿似然的「指数倾斜子模型」修正一步。所以 TMLE = 灵活的机器学习初估计 + 面向目标参数的定向修正，这也是它区别于普通「机器学习套一层公式」的关键。

背景与解释

「扰动函数」（nuisance functions，结局回归 \(Q\) 和倾向得分 \(g\)）是流行病学读者熟悉的老朋友，只是换了名字：它们就是我们做观察性研究时真正要「对付」的中间模型。半参数效率理论回答了一个自然的问题——既然我们只关心 \(\Psi\)，为什么还要认真估计这些「顺带」的量？答案是：虽然它们叫「扰动」函数，估计质量却直接影响最终效应估计的方差与偏差；效率理论给出了两者质量的最低要求（乘积率收敛），TMLE 的构造正是为了「榨干」效率——达到半参数效率下界。与临床研究的类比：就像即使最终报告的是相对危险度，也必须认真测量混杂因素，因为它们决定校正是否到位。用临床语言说，达到这个效率下界意味着：同等样本量下，TMLE 的置信区间比朴素的加权或回归方法更窄，检验效能更高——对样本量有限、效应又不大的临床研究尤其有价值。

10.1.1 双稳健性与 TMLE

平均处理效应的有效影响函数形式如下：

\[D^*(O) = \frac{A(Y - \bar{Q}(A,W))}{g(A|W)} - \frac{(1-A)(Y - \bar{Q}(A,W))}{1-g(A|W)} + \bar{Q}(1,W) - \bar{Q}(0,W) - \Psi(P_0)\]

其中 \(\bar{Q}(A,W) = \mathbb{E}[Y|A,W]\) 表示结局回归，\(g(A|W) = \mathbb{P}(A=1|W)\) 表示倾向得分。这一形式揭示了双稳健性：只要 \(\bar{Q}\) 或 \(g\) 中有一个设定正确，包含误设函数的那些偏差项就会渐近消失，从而得到因果参数的一致估计。

双稳健性的直觉来自嵌在影响函数中的校正机制。当结局模型 \(\bar{Q}\) 错误而倾向得分 \(g\) 正确时，加权残差 \(\frac{A(Y - \bar{Q}(A,W))}{g(A|W)} - \frac{(1-A)(Y - \bar{Q}(A,W))}{1-g(A|W)}\) 为结局模型的误差提供了无偏校正。反过来，当倾向得分错误而结局模型正确时，最后一项 \(\bar{Q}(1,W) - \bar{Q}(0,W)\) 直接给出了正确的因果对比。

TMLE 通过两阶段过程实现这些理论洞见：先用机器学习方法估计扰动函数，再施加靶向偏倚校正，使其表现针对特定因果参数优化。算法经由三个基本步骤，把初始估计转化为高效的因果参数估计。

第一步是用灵活的机器学习方法估计两个扰动函数。结局回归可以用随机森林、神经网络或集成方法，从 \(A\) 和 \(W\) 预测 \(Y\)，不作限制性参数假设。类似地，倾向得分估计也用机器学习从患者特征预测治疗分配，捕捉线性模型可能遗漏的复杂关系。

靶向（targeting）步骤是 TMLE 的核心创新。TMLE 不直接使用初始结局模型，而是拟合一个包含专门设计的协变量的参数子模型来更新它——这个协变量的唯一目的就是减小目标因果参数的偏差。这一巧妙参数化 \(\bar{Q}_n^*(\epsilon) = \bar{Q}_n^0 + \epsilon \cdot H(A,W)\)，其中 \(H(A,W) = \frac{A}{g_n(1|W)} - \frac{1-A}{g_n(0|W)}\)，保证了 \(\epsilon\) 的得分方程恰好等于有效影响函数的样本均值。

最后一步把更新后的结局模型代入，计算因果参数估计：\(\hat{\Psi} = \frac{1}{n}\sum_{i=1}^n[\bar{Q}_n^*(1,W_i) - \bar{Q}_n^*(0,W_i)]\)。这一「代入原理」保证我们的因果估计同时包含机器学习的灵活性和最优表现所必需的偏差校正。

背景与解释

双稳健性常被误读成「两个模型都错也没关系」——这是错的。它的准确含义是：只有一个模型错时结论仍然一致。本章 10.2 节专门用代码演示了三种情形：结局模型误设、倾向得分误设、两者都误设，读者可以亲眼看到只有前两种情形的估计保持稳定。与双稳健估计（doubly robust estimator，如 AIPW）的关系：AIPW 与 TMLE 估计的是同一个目标参数、共享同样的双稳健性，区别在于「外壳」——AIPW 直接把有效影响函数求平均，TMLE 则借道似然更新结局模型，因而自带效率保证与天然的置信区间构造；一个有用的记忆锚点是：TMLE 的最终估计 ≈ g-计算的估计 + 一个残差加权修正项，这个修正项就是它与普通标准化的全部差别。实践中两者结果通常非常接近，可以互为交叉验证。

背景与解释

Neyman 正交性（Neyman orthogonality）是双稳健性的「连续微分量」：粗略地说，它要求估计量对扰动函数误设的导数在真实参数处为零——即扰动函数的小误差只引起参数的二阶小偏差。双稳健性是「要么全有要么全无」（一个模型对就行），正交性则是「误差小时损失是二阶的」，让估计对模型质量的粗糙估计也不那么敏感。这也是为什么用机器学习（必然带估计误差）估计扰动函数时，人们偏爱具有正交性的估计量；DML、AIPW、TMLE 都属于这个家族。对医学读者的实际建议：不必会推导，但要知道——选方法时优先选带正交/双稳健性质的，能容忍你用 SuperLearner 而不是完美的参数模型。

10.2 医疗应用：降压治疗的比较有效性

我们将通过一项真实的比较有效性研究来演示 TMLE：考察 ACE 抑制剂（血管紧张素转换酶抑制剂）是否比钙通道阻滞剂（CCB）更有效地减少高血压患者的心血管事件。这一场景反映了常见的观察性研究情形——治疗选择取决于电子健康档案只能不完整捕捉的复杂患者特征，由此造成的混杂与测量难题，正是 TMLE 的用武之地。

我们模拟的患者人群包含人口学特征、合并症指标、实验室检查值和医疗服务利用模式，这些因素同时影响治疗选择和心血管结局。治疗分配机制反映了真实的临床决策过程：医生会同时权衡多个患者因素；而结局生成过程则同时包含直接处理效应以及患者特征与治疗反应之间的复杂交互。

  0.2 * sex +
  0.01 * (systolic_bp - 155) +
  0.01 * (diastolic_bp - 95) +
  0.4 * diabetes +
  0.3 * chronic_kidney_disease +
  0.6 * coronary_artery_disease +
  0.5 * heart_failure +
  0.1 * prior_hospitalizations +
  -0.5 * medication_adherence

  -0.1 * (medication_adherence - 0.8) * A     # 依从性交互作用

Y <- rbinom(n, 1, plogis(baseline_risk + treatment_effect))

用 SuperLearner 集成实现 TMLE

TMLE 的威力来自它与 SuperLearner 的集成。SuperLearner 是一种集成方法，它组合多个机器学习算法，为扰动函数估计达成最优的偏差–方差权衡。研究者无需锁定单一建模路线，SuperLearner 会根据交叉验证的表现，自动选出候选算法的加权组合。

# 定义用于估计扰动函数的 SuperLearner 算法库
# 纳入多样化算法，捕捉关系的不同侧面
SL_library <- c("SL.glm",           # 线性模型，保证可解释性
                "SL.glm.interaction", # 包含交互项
                "SL.stepAIC",        # 逐步选择
                "SL.randomForest",   # 基于树的集成
                "SL.glmnet")         # 正则化回归

# 用 SuperLearner 同时拟合结局模型与倾向得分模型
tmle_result <- tmle(Y = data$Y, 
                    A = data$A, 
                    W = data[, 1:14],  # 除处理与结局外的全部协变量
                    Q.SL.library = SL_library,
                    g.SL.library = SL_library,
                    family = "binomial")

# 提取结果
ate_tmle <- tmle_result$estimates$ATE$psi
ate_se <- sqrt(tmle_result$estimates$ATE$var.psi)
ate_ci_lower <- ate_tmle - 1.96 * ate_se
ate_ci_upper <- ate_tmle + 1.96 * ate_se
ate_pvalue <- 2 * (1 - pnorm(abs(ate_tmle / ate_se)))

cat("TMLE Results:\n")
## TMLE Results:
cat("Average Treatment Effect:", round(ate_tmle, 4), "\n")
## Average Treatment Effect: -0.001
cat("Standard Error:", round(ate_se, 4), "\n")
## Standard Error: 0.0096
cat("95% Confidence Interval: [", round(ate_ci_lower, 4), ",", round(ate_ci_upper, 4), "]\n")
## 95% Confidence Interval: [ -0.0199 , 0.0178 ]
cat("P-value:", round(ate_pvalue, 4), "\n")
## P-value: 0.9138
cat("Risk Difference (%):", round(100 * ate_tmle, 2), "%\n")
## Risk Difference (%): -0.1 %

结果解读：这是全书最重要的输出之一。TMLE 估计的 ATE 为 −0.001（即风险差 −0.1 个百分点），标准误 0.0096，95% CI [−0.0199, 0.0178]，P = 0.91。与粗估计（+0.97 个百分点）相比：符号翻转了——校正混杂后，ACEI 从「看起来有害」变成「小幅获益但远未达到统计学显著」。注意 tmle 包返回的 psi 是概率尺度上的差（−0.001 = −0.1 个百分点），报告时换算成百分点更便于临床读者理解。P 值远大于 0.05 表示「数据不足以证明有效」，而不是「证明无效」——置信区间 [−2.0, +1.8] 个百分点仍包含小幅到中等幅度的获益。

# 与朴素估计和校正估计作比较
crude_diff <- mean(data$Y[data$A == 1]) - mean(data$Y[data$A == 0])
glm_model <- glm(Y ~ A + ., data = data, family = binomial)
glm_ate <- mean(predict(glm_model, newdata = transform(data, A = 1), type = "response")) -
           mean(predict(glm_model, newdata = transform(data, A = 0), type = "response"))

cat("\nComparison of Methods:\n")
## 
## Comparison of Methods:
cat("Crude difference:", round(100 * crude_diff, 2), "%\n")
## Crude difference: 0.97 %
cat("Logistic regression ATE:", round(100 * glm_ate, 2), "%\n")
## Logistic regression ATE: 0.31 %
cat("TMLE ATE:", round(100 * ate_tmle, 2), "%\n")
## TMLE ATE: -0.1 %

方法比较解读：三种估计放在一起看——粗差异 +0.97 个百分点（混杂方向：ACEI 组被分配了更高危的患者，把 ACEI 推向有害）；logistic 回归标准化后降到 +0.31 个百分点（predict(type="response") 再对全人群取均值，即 g-计算式的边际标准化）；TMLE 进一步校正到 −0.1 个百分点。趋势很清晰：校正越充分，估计越接近「无获益」。注意 logistic 回归只做到部分校正（线性可加假设漏掉了交互与非线性），而 TMLE 靠 SuperLearner 捕捉到了这些结构，最终符号才翻过来。

SuperLearner 集成方法会自动适应底层关系的复杂程度，不要求研究者指定正确的函数形式。通过纳入线性模型、交互项、正则化回归和基于树的方法，集成既能捕捉平滑的线性关系，也能捕捉复杂的非线性模式，同时借助交叉验证避免过拟合。

背景与解释

SuperLearner 与流行病学的「模型平均」思路相通：与其赌一个模型对，不如让数据说话。它的两个关键设计值得注意：（1）用交叉验证的损失（如对数似然）给每个候选算法打分，按表现加权；（2）候选库应「多样化」——本书选了 SL.glm（无交互）、SL.glm.interaction（有交互）、SL.stepAIC、SL.randomForest、SL.glmnet，覆盖了从参数到非参数的谱系。临床研究中对应「先验地保留几种合理的分析模型，再用数据选择」。需要警惕的是：当样本量小或结局事件极少时，交叉验证本身不稳定，SuperLearner 的权重可能剧烈波动——此时 TMLE 的效率优势会打折扣。本例 575 例 ACEI 对 4425 例 CCB 的不均衡（约 1:7.7）在药物比较研究中相当典型，处理组越小，ATE 估计的方差越大；本例 SE 为 0.0096（约 1 个百分点），若效应本身只有 2–3 个百分点，就需要数千例才能达到满意效能，这与 RCT 样本量估算的逻辑一致。

考察模型表现与诊断

了解扰动函数模型的表现如何，对判断 TMLE 估计的可靠性至关重要。双稳健性意味着一个模型的糟糕表现可以被另一个模型的好表现补偿，但两个模型都检查才能全面评估估计质量。

背景与解释

倾向得分重叠图是观察性研究审稿中的「标配图」，读图要点有三：（1）两组分布在横轴上是否大范围交叠——若 ACEI 集中在低分段、CCB 集中在高分段，说明两组患者「根本不是一类人」，任何匹配/加权都无能为力；（2）低分段和高分段是否有一组「缺席」——缺席的区域没有反事实，对应效应不可识别；（3）整体形状——本例呈右偏单峰，多数人得分 0.05–0.20。它与流行病学的「标准化差异（SMD）」互补：SMD 看单个协变量，重叠图看整个倾向得分空间，两者都要过关；严格的做法还会报告重叠区域内的样本损失比例（trimming 后剩多少）。

理解靶向步骤

靶向步骤是 TMLE 对因果推断的独特贡献：它把初始的机器学习估计转化为偏差校正后的估计，使其专门针对目标因果参数优化。仔细考察这一步，能看清 TMLE 如何获得它的理论性质。

# 详细考察靶向步骤
initial_Q <- tmle_result$Qinit$Q[1]
targeted_Q <- tmle_result$Qstar[1]
epsilon <- tmle_result$epsilon

cat("Targeting Step Analysis:\n")
## Targeting Step Analysis:
cat("Targeting parameter (epsilon):", round(epsilon[1], 6), "\n")
## Targeting parameter (epsilon): -0.004251
cat("Mean initial outcome prediction:", round(mean(initial_Q), 4), "\n")
## Mean initial outcome prediction: 0.0423
cat("Mean targeted outcome prediction:", round(mean(targeted_Q), 4), "\n")
## Mean targeted outcome prediction: 0.0422
cat("Mean absolute targeting adjustment:", round(mean(abs(targeted_Q - initial_Q)), 6), "\n")
## Mean absolute targeting adjustment: 0.000197

靶向步骤解读：三个数字对比着看。靶向参数 \(\epsilon = -0.0043\)：注意它本身不等于 ATE，它只是子模型的步长——但本例中两者数值接近，因为结局模型的偏差恰好主要体现在均值偏移上。初始结局预测均值 0.0423 与靶向后的 0.0422 几乎没变，平均绝对调整量仅 0.000197（约万分之二）——说明初始的 SuperLearner 结局模型对总体风险水平的估计已经相当准确，靶向修正只是「精雕细琢」。这正是双稳健性起作用的形态：结局模型和倾向得分模型都不错，谁都不需要大修。

# 计算靶向中使用的聪明协变量 H(A,W)
H_1 <- data$A / g_estimates
H_0 <- (1 - data$A) / (1 - g_estimates)
clever_covariate <- H_1 - H_0

cat("Clever Covariate Statistics:\n")
## Clever Covariate Statistics:
cat("Mean H(A,W):", round(mean(clever_covariate), 4), "\n")
## Mean H(A,W): -0.0019
cat("SD H(A,W):", round(sd(clever_covariate), 4), "\n")
## SD H(A,W): 3.3011
cat("Range H(A,W): [", round(min(clever_covariate), 4), ",", round(max(clever_covariate), 4), "]\n")
## Range H(A,W): [ -1.3265 , 19.1857 ]

聪明协变量解读：\(H(A,W)\) 的均值约 −0.0019（接近 0，与 \(\epsilon\) 同号同量级，因为靶向就是让它的加权残差均值为零），但标准差高达 3.30、最大值达 19.19——少数患者的权重是普通患者的数十倍。这些正是倾向得分最低（约 0.048）的 ACEI 患者：他们「本该不用 ACEI 却用了」，其结局信息对估计处理效应极有价值，所以被算法赋予高权重。注意 \(H(A,W)\) 与 IPW 权重是「对偶」关系：同样以倾向得分倒数加权，但 IPW 直接加权结局，而 \(H\) 作为协变量去更新结局模型——这正是 TMLE 把两种策略缝在一起的针脚。分布如此分散也提醒我们：即便本例整体正值性良好，少数极端权重仍可能放大方差，报告估计时务必同时报告 SE 与 CI。

稳健性分析与敏感性检验

TMLE 的双稳健性提供了对模型误设的保护，但理解这种保护需要系统评估估计质量如何依赖扰动函数的估计精度。我们可以通过故意误设一个模型、保持另一个正确，来评估稳健性。

# 通过误设结局模型来检验双稳健性
# 只用线性项，而不是灵活的 SuperLearner
tmle_misspec_Q <- tmle(Y = data$Y,
                       A = data$A,
                       W = data[, 1:14],
                       Q.SL.library = "SL.glm",        # 误设的结局模型
                       g.SL.library = SL_library,      # 正确的倾向得分模型
                       family = "binomial")

# 通过误设倾向得分模型来检验双稳健性  
tmle_misspec_g <- tmle(Y = data$Y,
                       A = data$A,
                       W = data[, 1:14],
                       Q.SL.library = SL_library,      # 正确的结局模型
                       g.SL.library = "SL.glm",        # 误设的倾向得分模型
                       family = "binomial")

# 检验完全误设的情形
tmle_misspec_both <- tmle(Y = data$Y,
                          A = data$A,
                          W = data[, 1:14],
                          Q.SL.library = "SL.glm",      # 两个模型都误设
                          g.SL.library = "SL.glm",
                          family = "binomial")

# 比较估计
results_comparison <- data.frame(
  Method = c("Full SuperLearner", "Misspec Outcome", "Misspec Propensity", "Both Misspec"),
  ATE = c(tmle_result$estimates$ATE$psi,
          tmle_misspec_Q$estimates$ATE$psi,
          tmle_misspec_g$estimates$ATE$psi,
          tmle_misspec_both$estimates$ATE$psi),
  SE = c(sqrt(tmle_result$estimates$ATE$var.psi),
         sqrt(tmle_misspec_Q$estimates$ATE$var.psi),
         sqrt(tmle_misspec_g$estimates$ATE$var.psi),
         sqrt(tmle_misspec_both$estimates$ATE$var.psi))
)

results_comparison$CI_Lower <- results_comparison$ATE - 2.5 * results_comparison$SE
results_comparison$CI_Upper <- results_comparison$ATE + 2.5 * results_comparison$SE


# 可视化稳健性
p3 <- ggplot(results_comparison, aes(x = Method, y = ATE)) +
  geom_point(size = 3, color = "darkblue") +
  geom_errorbar(aes(ymin = CI_Lower, ymax = CI_Upper), width = 0.2, color = "darkblue") +
  geom_hline(yintercept = ate_tmle, linetype = "dashed", color = "red", alpha = 0.7) +
  labs(title = "TMLE Robustness to Model Misspecification",
       subtitle = "Double robustness protects against single model failures",
       x = "Modeling Approach", 
       y = "Average Treatment Effect") +

        axis.text.x = element_text(angle = 45, hjust = 1))

print(p3)

这一稳健性分析在实践中演示了 TMLE 的双稳健性。当结局模型或倾向得分模型中有一个设定正确（通过 SuperLearner）时，估计保持稳定、接近完全设定下的结果。然而当两个模型都误设时，偏差就可能出现——这凸显了至少对一个扰动函数采用灵活建模的重要性。

背景与解释

这个「人为弄坏一个模型」的实验建议成为读者自己论文中的标配敏感性分析：把 SuperLearner 换成纯线性模型（或只用主效应对比只用含交互的模型），看 ATE 是否稳定。读图时注意三点：（1）置信区间用的是 \(\pm 2.5 \times SE\)（约 99% 区间）而非 1.96，视觉上更保守；（2）完全误设时点估计偏离但仍落在合理范围——这与理论一致（小样本下偏差有限，样本量增大才会充分暴露）；（3）一个隐藏的「幸运」设定——本例倾向得分的真实形式恰好是对数线性的（见生成代码里的 propensity_linear），所以「Misspec Propensity」情形里的 SL.glm 其实近乎正确，四个点都稳定部分是这个设定的功劳；若真实模型超线性（如含年龄平方项），「单模型误设」的演示会更鲜明。总之，若你的真实分析中「两个模型都误设」的版本给出方向不同的结论，说明估计对建模选择很敏感，必须如实报告。

临床解读与亚组分析

TMLE 分析显示，与钙通道阻滞剂相比，ACE 抑制剂使心血管事件减少约 2–3 个百分点——这是一个具有临床意义的差异，相当于每 40 名用 ACEI 替代 CCB 治疗的患者中，可避免 1 例心血管事件。这一发现与基于生物学机制和既往研究的临床预期一致。

背景与解释（译者注）

需要向读者如实说明：本段文字中「减少 2–3 个百分点」的表述，与上文代码实际输出的 TMLE 估计（−0.1 个百分点，95% CI [−2.0, +1.8]）并不吻合。从模拟数据的生成代码看，对数优势尺度上的基础处理效应为 −0.4，叠加交互项后，平均到概率尺度上的真实 ATE 大致在 −1 到 −2 个百分点量级；上面跑出来的 −0.1 个百分点受具体随机种子和有限样本影响。这个「文字与数字对不上」的现象在原书中存在，我们保留原文并在此指出——它本身也是个有益的提醒：论文中报告的数字必须与输出一致，审稿人首先核对的正是这一点。

# 考察有临床意义的亚组间的处理效应
# TMLE 可以估计特定患者人群的条件效应

# 定义有临床意义的亚组
diabetes_patients <- data$diabetes == 1
heart_failure_patients <- data$heart_failure == 1
elderly_patients <- data$age > 70
high_risk_patients <- (data$cad == 1 | data$heart_failure == 1 | data$diabetes == 1)

subgroups <- list(
  "Diabetes" = diabetes_patients,
  "Heart Failure" = heart_failure_patients, 
  "Elderly (>70)" = elderly_patients,
  "High Risk" = high_risk_patients
)

subgroup_results <- data.frame(
  Subgroup = character(0),
  N = numeric(0),
  ATE = numeric(0),
  SE = numeric(0),
  P_value = numeric(0)
)

for(subgroup_name in names(subgroups)) {
  subgroup_idx <- subgroups[[subgroup_name]]
  
  if(sum(subgroup_idx) > 100) {  # 确保样本量充足
    subgroup_data <- data[subgroup_idx, ]
    
    tmle_sub <- tmle(Y = subgroup_data$Y,
                     A = subgroup_data$A,
                     W = subgroup_data[, 1:14],
                     Q.SL.library = SL_library,
                     g.SL.library = SL_library,
                     family = "binomial")
    
    ate_sub <- tmle_sub$estimates$ATE$psi
    se_sub <- sqrt(tmle_sub$estimates$ATE$var.psi)
    p_sub <- 2 * (1 - pnorm(abs(ate_sub / se_sub)))
    
    subgroup_results <- rbind(subgroup_results, data.frame(
      Subgroup = subgroup_name,
      N = sum(subgroup_idx),
      ATE = ate_sub,
      SE = se_sub,
      P_value = p_sub
    ))
  }
}

cat("Subgroup Analysis Results:\n")
## Subgroup Analysis Results:
subgroup_results$Risk_Diff_Percent <- round(100 * subgroup_results$ATE, 2)
subgroup_results$CI_Lower <- round(100 * (subgroup_results$ATE - 1.96 * subgroup_results$SE), 2)
subgroup_results$CI_Upper <- round(100 * (subgroup_results$ATE + 1.96 * subgroup_results$SE), 2)

print(subgroup_results[, c("Subgroup", "N", "Risk_Diff_Percent", "CI_Lower", "CI_Upper", "P_value")])
##        Subgroup    N Risk_Diff_Percent CI_Lower CI_Upper    P_value
## 1      Diabetes 1709              1.11    -2.21     4.44 0.51087927
## 2 Heart Failure  774             -0.76    -7.37     5.84 0.82062344
## 3 Elderly (>70) 1691              1.98    -0.15     4.11 0.06845597
## 4     High Risk 3036              0.08    -2.42     2.59 0.94759987

亚组分析结果解读：逐行读——糖尿病 1709 人，风险差 +1.11 个百分点（CI [−2.21, 4.44]，P = 0.51）；心衰 774 人，−0.76（CI [−7.37, 5.84]）；老年（>70 岁）1691 人，+1.98（CI [−0.15, 4.11]，P = 0.07）；高危（冠心病/心衰/糖尿病任一）3036 人，+0.08（CI [−2.42, 2.59]）。四个亚组的置信区间全部跨过 0，且都相当宽——每个亚组里 ACEI 使用者只有一两百人、事件数更少，噪声很大。正确的结论是「未发现统计学上显著的亚组差异」，而不是「某亚组有效/某亚组有害」。注意代码里 if(sum(subgroup_idx) > 100) 的守门条件：亚组太小就不做 TMLE，这是避免小样本崩溃的实用设计。

亚组分析揭示了与临床理解一致的处理效应异质性。糖尿病和心衰患者从 ACE 抑制剂中获益更大，反映了降压之外额外的心血管保护机制。老年患者获益较小，可能反映了竞争风险或对治疗的生理反应性下降。

背景与解释（译者注）

本段文字与上表的两处出入需要向读者说明：（1）文字称「糖尿病和心衰患者获益更大、老年患者获益较小」，但上表点估计方向并不支持（糖尿病 +1.11、老年 +1.98，均为正 = 事件更多）——不过所有置信区间都跨 0，这些点估计的波动完全在随机误差范围内，谈不上「与临床理解一致」，严谨的表述是「没有足够证据表明效应在这些亚组间存在差异」；（2）要下异质性结论，应报告效应修饰的交互检验（治疗 × 亚组的交互项 P 值）或改用因果森林（第 12 章），而不是逐亚组看 P 值——后者正是本书 1.4 节警告过的比较陷阱在亚组分析中的翻版。

「每个亚组单独跑一次 TMLE」在方法上是「按亚组分层估计条件 ATE」，它与「在交互模型中估计 CATE」是两条技术路线。分层法的优点是直观、每个亚组内独立校正混杂；缺点是样本被切细后方差暴涨（本例心衰亚组 CI 宽达 13 个百分点），且多重比较未校正。临床可借鉴的实践：亚组分析必须预设（方案里写清楚哪几个亚组、基于什么生物学理由）、报告交互 P 值而非各亚组各自的 P 值、并对亚组间的「差异」本身给出置信区间。指南（如 CONSORT、STROBE）对亚组分析的要求正是如此。

10.3 局限性与实践实施

TMLE 与所有观察性因果推断方法共享同一根本局限，其中最著名的就是「无未测混杂」这一不可检验的假设。在医疗场景中，疾病严重程度、患者偏好、医生执业模式等未测量因素，无论方法多复杂都可能使处理效应估计产生偏倚。考察「在不同未测混杂假设下结论会如何变化」的敏感性分析，对负责任的解读而言仍不可或缺。

该方法依赖机器学习估计扰动函数，这在有限样本中可能引入不稳定性。SuperLearner 虽然提供了交叉验证的模型选择，但集成权重在自助样本或数据子集间可能大幅波动，导致因果估计不稳定。这种不稳定性对较小的数据集影响尤甚——交叉验证此时可能无法给出可靠的算法选择。

正值性假设要求特征相似的患者接受任一治疗的概率都为正。在医疗场景中，强临床禁忌证或指南可能在协变量空间的某些区域使治疗分配近乎确定。当倾向得分接近 0 或 1 时，聪明协变量的权重变得极端，导致估计不稳定、标准误膨胀。截尾策略可以缓解这一问题，但会引入需要仔细权衡的偏差–方差取舍。

TMLE 的替代方法各有优势，取决于具体研究情境。增广逆概率加权（AIPW）以更简单的实现提供类似的双稳健性，但缺少 TMLE 的理论效率保证。双重机器学习（DML）方法通过不同的样本拆分策略实现类似的稳健性，在某些设定下可能有计算优势。贝叶斯方法能很自然地纳入模型设定的不确定性，但需要更强的分布假设和更复杂的实现。

TMLE 的计算强度源于 SuperLearner 集成方法：它需要为每个扰动函数拟合多个带交叉验证的机器学习算法。在拥有数十万患者、众多协变量的大型医疗数据集中，若不精心设计实现策略，计算时间可能变得令人望而却步。

计算最繁重的环节是 SuperLearner 交叉验证：通常对每个候选算法做 10 折交叉验证。若结局模型和倾向得分模型各用 5 个候选算法，一次 TMLE 分析就需要拟合 100 个模型（10 折 × 5 算法 × 2 个扰动函数）。多核并行处理能大幅缩短运行时间，对随机森林这类「易并行」算法尤其如此。

内存需求随样本量和机器学习算法的复杂度同步增长。随机森林等基于树的方法在处理大数据集时可能占用大量内存，而惩罚回归等简单算法则更省内存。面对海量医疗数据集的研究者，可能需要在集成复杂度与计算可行性之间取舍，比如用更小的 SuperLearner 库或更高效的算法。

TMLE 理论保证背后的「诚实性原则」（honesty principle）要求样本拆分，这会减小每个模型的有效样本量。这在统计效率与计算可行性之间造成了实际权衡。在中等规模的数据集中，样本拆分加上交叉验证可能产生不稳定估计——这说明 TMLE 或许最适合大型医疗数据库：充足的数据才能同时支撑样本拆分和复杂的集成建模。

近来的方法学发展把 TMLE 扩展到医疗研究中日益复杂的因果问题。纵向 TMLE（longitudinal TMLE）处理时变治疗与时变混杂，使分析「动态治疗方案」成为可能——在这类方案中，治疗决策随患者反应和临床状态的变化而演进。这一扩展对慢性病管理尤其有价值，因为治疗强化或调整正是基于持续监测做出的。

使用 TMLE 的中介分析（mediation analysis）把处理效应分解为直接通路与经由中间变量起作用的间接效应。在药物研究中，这可能意味着弄清药物的获益有多少来自预期的生物学通路、多少来自次级机制。TMLE 框架保证直接效应与间接效应的估计在现实条件下都保持良好的统计性质。

生存分析扩展处理带删失的至事件时间（time-to-event）结局，这在医疗场景中很常见——患者可能死亡、转换治疗或失访。这些方法需要仔细处理竞争风险与信息性删失，同时保持使 TMLE 在观察性研究中颇具吸引力的双稳健性。

TMLE 框架内的变量重要性度量（variable importance measures）识别哪些患者特征对处理效应异质性贡献最大。与可能被模型设定混杂的传统回归系数不同，基于 TMLE 的重要性度量给出协变量与治疗决策相关性的稳健排序。这一能力支持精准医学计划——找出应当指导治疗选择的患者特征。

现代医疗产生了海量的电子健康档案（EHR）数据库，这为 TMLE 的实施既带来机会也带来挑战。EHR 中丰富的纵向数据使全面的混杂控制成为可能，但也引入了可能损害因果推断的数据质量问题。缺失数据的模式可能与治疗分配和结局都相关，若处理不当就会违反 TMLE 的假设。

EHR 数据的时间结构要求仔细斟酌基线协变量的定义与随访窗口。处理效应可能随起始后的时间变化，随访期的选择会实质影响估计。TMLE 框架通过仔细的问题设定容纳这些复杂性，但实践者必须对时间窗和协变量测量时点做出明确选择。

含数千个潜在混杂的高维 EHR 数据受益于 TMLE 的机器学习集成，但计算挑战也随之加剧。降维技术或变量选择程序可能是必要的预处理步骤——尽管它们会引入额外的建模假设，可能影响双稳健性。

跨医疗系统标准化 EHR 数据的真实世界证据平台日益普及，为开展外部效度更佳的大规模 TMLE 分析创造了机会。使用 TMLE 的多站点分析可以把不同医疗环境下的证据汇总起来，同时通过适当的协变量调整顾及各站点特有的混杂模式。

成功实施 TMLE 需要系统关注几个连接理论性质与真实数据挑战的实践要点。样本量规划应计入样本拆分和交叉验证固有的效率损失，通常比传统回归方法需要更大样本才能达到同等精度。少于几千例观测的医疗数据集可能无法为稳定的 TMLE 估计提供足够效能，在考察大量潜在混杂时尤其如此。

尽管 TMLE 很灵活，协变量选择依然关键。纳入「能预测治疗分配或结局但不是混杂因子」的变量可提升效率，而纳入工具变量则可能通过「只增方差、不减偏差」损害表现。临床知识应指导初始的变量选择，机器学习方法则负责函数形式设定与交互检测。

诊断程序应同时评估扰动函数模型的表现与假设的有效性。倾向得分分布应在治疗组间显示充分重叠，结局模型残差应与患者特征无关，影响力观测诊断应识别出「剔除后会显著改变估计」的患者。这些诊断有助于区分方法局限与数据质量问题。

结果报告应同时强调统计学显著性与临床相关性。风险差尺度往往比比值比提供更直观的解读，特别是在与临床受众沟通时。需治人数（NNT）计算把风险差转化为支持循证实践的临床决策框架。

TMLE 框架持续演进，以应对医疗研究中日益复杂的因果问题。深度学习和自动特征工程等机器学习进展有望改进扰动函数估计，同时提升 TMLE 估计的灵活性与稳定性。然而这些进展必须与可解释性要求和计算约束相平衡。

与因果发现方法（causal discovery）的整合，为「从数据中识别混杂结构、而非仅依赖临床知识」提供了可能。尽管纯数据驱动的方法无法取代领域专长，但把算法发现与临床输入相结合的混合方法，可以改善协变量选择与模型设定。

随着 TMLE 分析为临床指南和治疗建议提供依据——而这些建议可能对不同患者人群产生不同影响——公平性考量变得越来越重要。要确保个体化治疗建议促进而非加剧健康不平等，就需要对社会人口学特征的公平性度量与亚组分析给予明确关注。

精准医学日益受到重视，这对 TMLE 扩展提出了新需求：估计个体化治疗规则而不仅是平均效应。这些方法必须在个体化收益、统计效率与可解释性成本之间取得平衡，同时保持使 TMLE 在高风险临床决策中颇具吸引力的理论严谨性。

背景与解释

本节提到的三个扩展方向，恰好对应流行病学最熟悉的三个战场，值得展开：（1）纵向 TMLE——随访中治疗随病情调整（如降压药逐步加量）时，时变混杂（每次访测的血压、依从性都影响下次调药）会让传统方法失效，ltmle 包正是为此设计，与 Robins 的边际结构模型（MSM，第 8 章）是「同一问题的两种解法」，可以互相验证；（2）生存数据——临床研究的默认结局往往不是二值事件而是「至事件时间 + 删失」，TMLE 处理它时需要把结局回归换成生存模型、并妥善处理竞争风险（如心血管死亡 vs 非心血管死亡）与信息性删失，此时「双稳健」的论证更精细，报告时应说明删失机制的假设；（3）个体化治疗规则——这是精准医学的核心问题（「谁该用什么药」），估计目标从 ATE 变成 CATE 或价值函数，需要的数据量与诊断都更苛刻，建议读者先把单时点 ATE 做扎实，再进阶到这些扩展。

10.4 结论

靶向极大似然估计（TMLE）代表了观察性因果推断的一次根本性进展，它直接回应了医疗研究者分析电子健康档案与行政数据库时面临的核心挑战。通过把机器学习的灵活性与半参数理论的统计严谨性结合起来，TMLE 为「从复杂的观察性数据中提取因果洞见、同时不依赖限制性参数假设」提供了有原则的框架。双稳健性在医疗场景中提供了对抗模型误设的关键保护——复杂的患者特征、治疗分配机制和结局过程，在那里抗拒一切简单的参数描述。这种稳健性伴随着计算成本和样本量要求，可能限制其在小型研究中的适用性；但大型医疗数据库日益普及，正使这些要求越来越容易满足。

我们的降压治疗分析演示了 TMLE 如何提供具有临床可操作性的比较有效性洞见，同时通过诚实的置信区间承认不确定性。该方法能够容纳复杂的混杂模式、缺失数据机制和机器学习方法，这使它特别适合现代医疗研究环境——传统方法在那里可能力不从心。TMLE 背后的理论保证确保：在识别假设成立时，估计达到最优统计性质，与逆概率加权或单纯结局回归等简单方法相比具有效率优势。这些效率增益直接转化为检测具有临床意义的处理效应时更高的检验效能，以及更窄的置信区间，从而支持更明确的临床推荐。

随着医疗界日益拥抱精准医学与真实世界证据生成，TMLE 集灵活性、稳健性与效率于一身的特性，使它成为因果推断的必备工具。该方法通过向纵向数据、生存结局和个体化治疗规则的扩展持续发展，确保它能回应现代医疗研究中那些复杂的因果问题。成功的实施需要认真关注计算考量、诊断程序和假设验证；但对方法复杂性的投入，会通过更可靠的因果估计获得回报——这些估计能够指导临床实践和卫生政策决策。在与充足样本量和有效识别假设相结合的前提下妥善应用，TMLE 为「把观察性医疗数据转化为可操作的因果知识、改善患者结局和医疗服务」提供了强大框架。
