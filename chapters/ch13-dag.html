第 13 章 有向无环图：描绘医疗决策的因果架构

原书第 13 章 · directed-acyclic-graphs-mapping-the-causal-architecture-of-healthcare-decisions.html · Kamran Afzali《Causal Inference in R》中文译本 · 非官方翻译

13.1 引言

假设你正在分析一项新的糖尿病筛查项目能否降低心血管并发症。观察性数据显示，接受筛查的患者结局更好，但这是因为筛查真的有效，还是因为更健康、更有健康意识的患者更有可能接受筛查？也许社会经济地位通过获得预防保健和健康生活方式的机会，同时影响了筛查参与和健康结局。或者关系是反的——出现早期症状的患者更积极地寻求筛查，从而在筛查与结局之间制造出虚假关联。

这些问题反映了因果推断的根本挑战：理解观测关联背后真实的因果结构。筛查与结局之间的关联可能通过多条通路产生，而其中只有一部分代表真正的因果效应。如果不显式地梳理这些关系，我们就有可能得出无效的结论，导致干预措施失灵或资源浪费。

有向无环图（directed acyclic graphs，DAG）为阐述我们对系统中因果关系的假设提供了一种正式的可视化语言。与描述数据中关联的统计模型不同，DAG 表示的是潜在的数据生成过程本身——产生我们所观测模式的真实因果机制。这一区别至关重要，因为同一个统计关联可能源自根本不同的因果结构，而每一种结构都需要不同的分析策略才能有效地识别因果效应。

DAG 的力量不在于它有能力从数据中发现因果关系——没有哪种纯粹的统计方法能在缺乏强假设的情况下可靠地做到这一点——而在于它能使我们的因果假设变得明确、可检验、可操作。通过迫使研究者在分析数据之前阐明他们对因果结构的看法，DAG 把因果推断从非正式的「讲故事」练习，转变为一个严谨的分析框架，对研究设计与统计调整都有清晰的含义。

有向无环图由表示变量的节点和表示直接因果效应的有向边组成。「有向」指边带有箭头以表明因果方向——如果吸烟导致肺癌，我们从吸烟向肺癌画箭头，而不是反过来。「无环」禁止变量通过任何因果路径序列导致自身的反馈回路，确保图表达的是连贯的事件时间顺序。

考虑一个联系用药依从性、健康结局和医疗费用的简单医疗示例。我们可能假设：依从性直接改善健康结局，健康结局进而降低医疗费用。这翻译成 DAG 结构就是：依从性 → 结局 → 费用。从依从性到费用没有直接箭头，代表我们相信依从性只通过影响健康结局来影响费用，而不是通过其他机制。

背景与解释

医学研究者对「因果图」并不陌生。流行病学中的有向无环图传统可追溯到 20 世纪 90 年代：Greenland、Pearl 与 Robins (1999) 把 Pearl 的图模型系统引入流行病学，此前的 Sander Greenland 与 James Robins 已用「因果图」分析混杂结构，Robins later 还发展了「单一世界干预图」（switched acyclic graphs）。它与教科书中的两类经典框架形成互补：Rothman 的「充分组分病因模型」（因果派，causal pies）回答的是「一个病例由哪些病因组分凑合而成」，适合思考病因组合与交互；DAG 回答的是「变量之间如何相互关联、该调整哪些变量」，适合思考研究设计与偏倚来源。实用建议：写观察性研究论文时，用一张 DAG 向审稿人说明「我们认为的混杂结构」和「据此选择的调整变量集」，比在文字里罗列「我们调整了年龄、性别……」更有说服力，这也是近年 NEJM、JAMA、Lancet 系列期刊越来越常见的做法。

DAG 的数学形式化建立在结构因果模型（structural causal models）的概念之上。图中每个变量 \(V\) 由一个结构方程 \(V = f_V(Pa(V), U_V)\) 决定，其中 \(Pa(V)\) 表示图中 \(V\) 的父节点（直接原因）集合，\(U_V\) 表示影响 \(V\) 的未观测因素。这些方程描述的是「自然」如何生成数据，而非变量间如何在统计上相关。

因果马尔可夫假设（causal Markov assumption）构成了图结构与概率分布之间的桥梁。它指出：给定其父节点，每个变量与所有非后代变量独立。形式上，对图中任意变量 \(V\)，\(V \perp ND(V) | Pa(V)\)，其中 \(ND(V)\) 表示 \(V\) 的非后代集合。该假设使我们能够按图结构分解联合概率分布：\(P(V_1, \ldots, V_n) = \prod_{i=1}^{n} P(V_i | Pa(V_i))\)。

使 DAG 能够进行因果推断的根本洞见是 do-演算（do-calculus），它区分「观测一个变量」与「干预并将其设定为某个特定值」。当我们观测到一位患者在服药（\(X = x\)）时，我们是以自然发生的、受图中所有父节点影响的依从性模式为条件。而当我们干预以确保服药（\(do(X = x)\)）时，我们切断所有指向 \(X\) 的因果箭头，并强制 \(X\) 取值为 \(x\)，无论自然情况下会发生什么。依从性对结局的因果效应由干预分布 \(P(Y | do(X = x))\) 定义，而不是观测分布 \(P(Y | X = x)\)。

背景与解释

「观察还是干预」是因果推断区别于传统统计的分水岭，两种经典语言在这里汇合：Rubin 的反事实框架把处理 \(X\) 设为 \(x\) 后的潜在结局记为 \(Y(x)\)，平均处理效应为 \(E[Y(1) - Y(0)]\)；Pearl 的 do-演算则写作 \(P(Y | do(X = x))\)。两者在数学上等价（结构方程 + 独立性假设下可以互相推导），区别在风格：潜在结局框架对临床试验更亲切，do-演算对「图上的操作」更直观。对医学研究者，最有用的一招是把每个观察性研究问题翻译成「我想知道 \(P(Y | do(X))\)，我手上只有 \(P(Y | X)\)，差距在哪里、怎么补」——这个翻译过程会立刻暴露研究的识别假设。

理解信息如何在 DAG 中流动，能揭示哪些变量需要统计调整才能进行有效的因果推断。三种基本路径结构决定信息流动：链、叉和碰撞因子。在链 \(X \rightarrow M \rightarrow Y\) 中，信息通过中介 \(M\) 从 \(X\) 流向 \(Y\)。以 \(M\) 为条件阻断这条通路，在去除通过 \(M\) 的间接效应的同时，分离出 \(X\) 对 \(Y\) 的直接效应。在叉 \(X \leftarrow C \rightarrow Y\) 中，共同原因 \(C\) 诱导出 \(X\) 与 \(Y\) 之间的虚假关联。以 \(C\) 为条件阻断这条非因果通路，就能揭示出：在考虑共同原因之后，\(X\) 与 \(Y\) 是独立的。

碰撞因子结构 \(X \rightarrow C \leftarrow Y\) 的行为违反直觉。这里 \(X\) 与 \(Y\) 边际独立——它们之间没有任何因果连接——但以它们的共同效应 \(C\) 为条件，会诱导出 \(X\) 与 \(Y\) 之间的虚假关联。这一现象称为碰撞因子偏倚（collider bias）或选择偏倚（selection bias），是观察性研究中最常见的偏倚来源之一。如果我们把分析限制在出现并发症的患者中（并发症是一个由处理和潜在健康状况共同导致的碰撞因子），就会制造出处理与健康状况之间在全人群中并不存在的人为关联。

背景与解释

三种基本结构对应流行病学最熟悉的几类问题，值得一一对照：叉（共同原因）就是「混杂」——处理与结局的共同原因（如病情严重程度同时影响用药与死亡），调整它即可阻断虚假通路；链（中介）就是「中介效应」问题，调整中介估计的是直接效应，不调整才是总效应，调整与否取决于研究问题；碰撞因子就是「选择偏倚」，医疗场景中极其常见：只分析「到过某家医院的患者」「存活到出院的患者」「失访前仍在随访的患者」「愿意参加研究的患者」，只要入选/失访同时受处理与结局（或其共同原因）影响，就等于在碰撞因子上加了条件。一个更微妙的形式是 M 偏倚（M-bias）：\(X \leftarrow A \rightarrow B \leftarrow C \rightarrow Y\) 中，\(A\)、\(C\) 分别是处理和结局的原因，原本并无混杂，但若调整共同效应 \(B\)（如某个受两者影响的就诊行为），反而凭空制造出混杂。这就是为什么「先把能拿到的变量都放进模型」不是安全策略。

连接处理 \(X\) 与结局 \(Y\) 的一条路径，如果含有我们以其为条件的非碰撞因子，或者含有我们不以其为条件（也不以其任何后代为条件）的碰撞因子，则该路径被阻断。后门准则（backdoor criterion）为「一组变量 \(Z\) 是否足以识别 \(X\) 对 \(Y\) 的因果效应」提供了形式化检验：如果 \(Z\) 阻断了从 \(X\) 到 \(Y\) 的所有后门路径（即通过指向 \(X\) 的箭头进入 \(X\) 的路径），并且 \(Z\) 不包含 \(X\) 的任何后代，则 \(Z\) 满足后门准则。当后门准则满足时，我们就可以通过协变量调整来估计因果效应：\(P(Y | do(X = x)) = \sum_z P(Y | X = x, Z = z) P(Z = z)\)。

考虑估计一种糖尿病药物对心血管事件的因果效应。DAG 可能包含：药物 \(X\)、心血管事件 \(Y\)、病情严重程度 \(S\)、年龄 \(A\) 和社会经济地位 \(E\)。因果箭头包括：\(A \rightarrow S\)、\(A \rightarrow Y\)、\(E \rightarrow X\)、\(E \rightarrow Y\)、\(S \rightarrow X\) 和 \(X \rightarrow Y\)。年龄和社会经济地位都通过后门路径混淆药物—结局关系。病情严重程度造成更复杂的结构——它混淆这一关系（病情更重的患者接受不同的药物），但如果药物通过改变病情进展发挥作用，它同时又中介处理效应。后门准则建议调整年龄和社会经济地位；至于病情严重程度是否需要调整，则要仔细斟酌，取决于我们追求的是总效应还是受控直接效应。

背景与解释

后门准则与「充分调整集」（sufficient adjustment set）是 DAG 对临床研究最实用的部分，它把「该调整哪些变量」从统计经验问题变成了可以推导的数学问题：只要 DAG 画对了，用 dagitty 的 adjustmentSets()、R 包 ggdag 或网页版 DAGitty 就能自动列出所有满足后门准则的变量集，从中挑一个测量质量好、缺失少的即可。几个实操要点：(1) 绝不能调整处理后变量（中介、碰撞因子及其后代），这是观察性研究中最常见的错误之一；(2) 调整集通常不唯一，例如共同原因的「上游」变量（调整年龄而不是同时调整年龄与年龄导致的疾病严重程度）只要满足准则也可以，此时优先调整与处理/结局关联强、测量精确的变量；(3) 仪器变量、代理变量（如用医保记录代替真实收入）也可以进 DAG，未测变量用带圆点的潜变量表示；(4) 工具变量分析可以看作「前门准则」（front-door criterion）的特例。把论文的调整变量集与 DAG 一起报告，方法学审稿人会清楚你是「有的放矢」而不是「 data-driven 捞变量」。

13.2 在医疗研究中实施 DAG 分析

现代软件实现通过直观的界面让 DAG 分析变得触手可及。dagitty 包提供了 DAG 设定、分析与可视化的综合工具，ggdag 则在 ggplot2 图形语法的基础上提供了优雅的可视化方案。让我们通过一个真实的医疗应用来探索 DAG 分析：考察他汀类药物能否降低心脏病患者的死亡率。

library(ggplot2)
library(dplyr)
library(broom)

# 设置随机种子以保证结果可重复
set.seed(456)

# 定义因果结构
# 变量：他汀（X）、死亡（Y）、年龄（A）、病情严重程度（S）、
# 胆固醇（C）、运动（E）、社会经济地位（SES）
dag <- dagitty('dag {
  Age [pos="0,0"]
  SES [pos="0,2"]
  Exercise [pos="1,2"]
  Cholesterol [pos="2,1"]
  Severity [pos="1,0"]
  Statins [exposure,pos="3,1"]
  Mortality [outcome,pos="5,1"]
  
  Age -> Severity
  Age -> Mortality
  Age -> Cholesterol
  SES -> Exercise
  SES -> Statins
  SES -> Mortality
  Exercise -> Cholesterol
  Exercise -> Mortality
  Cholesterol -> Severity
  Cholesterol -> Statins
  Severity -> Statins
  Severity -> Mortality
  Statins -> Mortality
  Statins -> Cholesterol
}')

# 可视化因果结构
ggdag(dag) +
  theme_dag() +
  labs(title = "Causal Structure: Statin Treatment and Mortality",
       subtitle = "Nodes represent variables, arrows represent direct causal effects")

输出解读：dagitty() 用 DOT 风格的字符串定义图：方括号里的 pos 指定节点坐标，exposure / outcome 把「他汀」和「死亡」标记为暴露与结局（绘图中会有特殊配色）。从 -> 列表可以读出全部假设的因果关系：年龄影响严重程度、死亡和胆固醇；社会经济地位影响运动、他汀使用和死亡；运动影响胆固醇和死亡；胆固醇影响严重程度和他汀使用；严重程度影响他汀和死亡；他汀影响死亡和胆固醇。图中可以直观看到：他汀与死亡之间既有直接因果箭头，也有大量经过 Age、SES、Cholesterol、Severity 的非因果路径。

# 运动取决于 SES

# 胆固醇取决于年龄和运动

# 病情严重程度取决于年龄和胆固醇
severity <- plogis(-5 + 0.04 * age + 0.01 * cholesterol)

# 他汀处方取决于 SES、胆固醇和严重程度
statin_prob <- plogis(-2 + 0.3 * ses + 0.01 * cholesterol + 2 * severity)
statins <- rbinom(n, 1, statin_prob)

# 他汀降胆固醇（反馈）
cholesterol_treated <- cholesterol - 40 * statins + rnorm(n, 0, 10)

# 死亡取决于年龄、SES、运动、严重程度和他汀
# 他汀的真实因果效应：风险比约 0.75（降低 25%）
mortality_prob <- plogis(-3 + 0.04 * age - 0.3 * ses - 0.4 * exercise + 
                        2 * severity - 0.6 * statins)
mortality <- rbinom(n, 1, mortality_prob)

  ses = ses,
  exercise = exercise,

  statins = statins,
  mortality = mortality

调整集分析识别出：为了有效地估计因果效应，我们必须测量并控制哪些变量。不同的调整集都可能满足后门准则，研究者可以基于测量质量、缺失数据模式或其他实际考量在它们之间选择。关键洞见在于：调整了错误的变量——或没能调整正确的变量——无论样本量多大、统计方法多复杂，都会产生有偏的因果估计。

背景与解释

这里值得停下来核对一处原文与输出的不一致：本节文字说「他汀使用者的粗死亡率高于非使用者」（higher observed mortality rates），但上面两行输出是 45.5% 对 54.2%——使用者明明更低。这不是翻译问题，原书即如此（很可能是文字按另一套参数写的，后来改了代码没改文字）。正确的读法应该是：粗关联方向为「保护」（OR ≈ 0.71，见 13.3 节），但真实效应更强（OR ≈ 0.55）；混杂偏倚在这里把估计拉向无效方向，而不是颠倒方向。由此可以纠正一个常见误解：混杂偏倚并不总会「制造出」虚假关联，它同样可以把真实存在的关联稀释掉。医学文献中「适应证混杂（confounding by indication）通常使治疗显得有害」的说法只描述了其中一种情形；偏倚方向取决于治疗分配与结局风险的相对关系，必须结合具体 DAG 判断。这个例子也示范了模拟研究的正确用法：先设定已知真值的数据生成过程，再看各种分析方法能否还原它。

背景与解释

细心的读者会发现：这张 DAG 同时包含 Cholesterol -> Statins 和 Statins -> Cholesterol 两条边——按定义这就构成了一个有向环，而「无环」正是 DAG 的题中之义（代码注释里也直白地写了 feedback）。这解释了两个悬而未决的现象：13.2 节 adjustmentSets() 为何没有任何输出（有环的图不存在有效的后门调整集），以及 13.4 节 ggdag_adjustment_set() 为何警告「Failed to close backdoor paths …… graph is not acyclic」。现实世界中，「他汀影响胆固醇、胆固醇水平又影响是否调整他汀」这种反馈确实存在，但 DAG 的表达力要求变量随时间（或测量时点）分层。标准修法有两种：(1) 拆分变量——把胆固醇拆成「基线 LDL」（治疗前的混杂因子：Cholesterol₀ → Statins）和「治疗后 LDL」（中介：Statins → Cholesterol₁ → Mortality），环自然消解，这与临床数据库中「基线值/随访值」的常见结构吻合；(2) 时间索引——按访视顺序画 Statins₁ → Chol₁ → Statins₂ → Chol₂ ……，形成一条链而非环。读者在自己的研究中遇到类似「互为因果」的结构时，都应优先考虑按测量时点拆层，而不是硬画成一个环。

背景与解释

「过度调整」值得医学研究者高度重视，它有两种不同机制。第一种是调整中介（本例的胆固醇）：他汀 → 降胆固醇 → 降死亡，把胆固醇放进模型等于问「在不改变胆固醇的前提下，他汀还有没有用」，估计的是受控直接效应而非总效应。如果真实世界还存在「他汀 → 死亡」的非胆固醇通路，直接效应与总效应并不相等，回归系数自然偏离总效应。第二种是调整碰撞因子或其后代：如 13.2 节路径 [3] 所示，胆固醇本身是碰撞结构上的节点，以它为条件反而打开新通路。Rothman 的经典警告「不要调整因果路径上的变量」与 M 偏倚讨论都是同一主题。实操 checklist：(1) 只调整「处理之前」就已确定的变量（基线协变量）；(2) 随访中测量的变量原则上都是候选中介或碰撞因子，除非你的估计目标就是直接效应（此时应明确用中介分析/自然直接效应的语言报告）；(3) 拿不准时问自己「这个变量在治疗开始时已经确定了吗」。本例中 exercise 被一并调整也值得商榷——运动可能是他汀使用的「代理」而非单纯混杂，取决于 DAG 怎么画，这正是 13.7 节强调「与临床专家共同画图」的原因。

13.5 敏感性与未测混杂

没有任何 DAG 能包含自然界中真正存在的所有变量。关键问题于是变成：未测变量会在多大程度上扭曲我们的因果估计。敏感性分析（sensitivity analysis）量化「未测混杂需要多强才能推翻我们的结论」。

observed_or <- minimal_or
observed_rr <- observed_or  # 罕见结局下的近似换算

## Warning in sqrt(observed_rr * (observed_rr - 1)): NaNs produced

##       2.516       0.960       1.337     581.309

输出解读：处理一侧的关联强度：年龄每岁 OR 0.960（几乎无关），SES 每单位 OR 1.337，而严重程度的 OR 高达 581——病情越重越可能用他汀，这是典型的适应证混杂。

measured_outcome <- glm(mortality ~ age + ses + severity, 
                       data = data, family = binomial())
cat("\nAssociation with Outcome (Mortality):\n")
## 
## Association with Outcome (Mortality):

输出解读：再算已测混杂因子对死亡的关联强度。

print(round(exp(coef(measured_outcome)), 3))
## (Intercept)         age         ses    severity 
##       0.036       1.031       0.729      14.394

输出解读：结局一侧的关联强度：年龄每岁 OR 1.031，SES OR 0.729，严重程度 OR 14.394。把两行对照着看，就能判断未测混杂「需要多强才危险」。

cat("\nIf unmeasured confounding is weaker than measured confounding,\n")
## 
## If unmeasured confounding is weaker than measured confounding,

输出解读：判断准则的上半句：如果未测混杂比已测混杂还弱……

cat("our causal conclusion remains robust.\n")
## our causal conclusion remains robust.

输出解读：……那么因果结论就是稳健的。本节代码到此结束。

敏感性分析为解读因果主张提供了关键背景。远大于已测混杂因子关联强度的 E 值，提示因果估计对未测混杂相对稳健。反之，小的 E 值意味着脆弱的结论，未测混杂可以轻易将其推翻。这一稳健性的定量评估，有助于研究者和临床医生评价因果证据的强度。

背景与解释

E 值（E-value）由 VanderWeele & Ding (2017, Annals of Internal Medicine) 提出，是观察性研究中最实用的敏感性分析工具之一：它回答「一个未测混杂因子需要同时与处理、结局有多强的关联（以风险比计，且取两者中的较弱者），才能把观察到的效应完全解释掉」。原书代码的问题在于公式只适用于 RR > 1 的情形；对于保护性效应（RR < 1），标准做法是先取倒数：本例 1/0.567 ≈ 1.76，再代入公式得 E 值 ≈ 1.76 + √(1.76 × 0.76) ≈ 2.92。也就是说：需要某个未测因子同时以约 2.9 倍的 OR 关联他汀使用和死亡，才能解释掉全部观察效应。把它与上面两行输出对照——已测的严重程度关联强度高达 581（处理侧）和 14.4（结局侧）——结论「稳健」是合理的；但要注意这是本例数据生成过程的产物（severity 系数被设得极大），真实研究中的已测混杂很少这么强。R 的 EValue 包（VanderWeele 等）可以直接算，无需手写公式。医学研究者写论文时，把 E 值与已测混杂的强度对照报告，比空口说「残余混杂可能有限」有说服力得多。

13.6 DAG 的可检验含义与验证

DAG 相对于非正式因果推理的一个关键优势是：它们生成可检验的条件独立性命题。如果提出的 DAG 准确代表了因果结构，这些独立性关系就应当在数据中成立。违反则提示模型误设。

cat("\n=== Testing DAG Implications ===\n\n")
## 
## === Testing DAG Implications ===

输出解读：检验环节的标题。

# DAG 蕴含特定的条件独立性
# 检验其中一个子集
# 检验 1：给定 SES 时，运动与年龄独立
test1 <- glm(exercise ~ age + ses, data = data, family = binomial())
p1 <- coef(summary(test1))["age", "Pr(>|z|)"]

cat("Test 1: Exercise ⊥ Age | SES\n")
## Test 1: Exercise ⊥ Age | SES

输出解读：检验 1 的命题：给定 SES 后，运动与年龄独立（图中运动只受 SES 影响，与年龄无路径）。做法是在 logistic 回归里看年龄系数是否为零。

cat(sprintf("  p-value = %.4f\n", p1))
##   p-value = 0.7356

输出解读：p = 0.7356，远不显著——没有证据反对「独立」，与 DAG 的预测一致。

cat(sprintf("  Result: %s\n\n", ifelse(p1 > 0.05, "PASS", "FAIL")))
##   Result: PASS

输出解读：PASS。注意「PASS」只是「未能否证」，不等于「证明为真」。

# 检验 2：给定 {年龄、严重程度、他汀、运动} 时，死亡与 SES 独立
test2 <- glm(mortality ~ ses + age + severity + statins + exercise,
             data = data, family = binomial())
p2 <- coef(summary(test2))["ses", "Pr(>|z|)"]

cat("Test 2: Mortality ⊥ SES | {Age, Severity, Statins, Exercise}\n")
## Test 2: Mortality ⊥ SES | {Age, Severity, Statins, Exercise}

输出解读：检验 2 的命题：给定 {年龄、严重程度、他汀、运动} 后，死亡与 SES 独立。

cat(sprintf("  p-value = %.4f\n", p2))
##   p-value = 0.0000

输出解读：p < 0.0001（显示为 0.0000）， SES 系数高度显著。

cat(sprintf("  Result: %s\n\n", ifelse(p2 > 0.05, "PASS", "FAIL")))
##   Result: FAIL

输出解读：FAIL。这个「失败」该如何解读，见下方「背景与解释」——它暴露的很可能不是 DAG 的问题，而是检验本身选错了命题。

cat("Note: Test failures suggest the DAG may be misspecified.\n")
## Note: Test failures suggest the DAG may be misspecified.

输出解读：原书的注释：检验失败提示 DAG 可能误设。

cat("Consider:\n")
## Consider:

输出解读：接下来三行列出误设的三个可能来源。

cat("  - Additional unmeasured confounders\n")
##   - Additional unmeasured confounders

输出解读：可能一：存在额外的未测混杂因子。

cat("  - Missing causal pathways\n")
##   - Missing causal pathways

输出解读：可能二：遗漏了因果通路。

cat("  - Measurement error in variables\n")
##   - Measurement error in variables

输出解读：可能三：变量存在测量误差。

这些经验检验为提出的因果结构提供了数据驱动的验证。虽然通过全部检验并不能证明 DAG 正确（多个不同的 DAG 可能蕴含相同的独立性命题），但检验失败明确表明存在误设，需要认真重新审视所假设的因果关系。

背景与解释

这节有一个容易被忽略的逻辑细节：Test 2 的「失败」很可能不是 DAG 的问题，而是检验选错了命题。回看 13.2 节 impliedConditionalIndependencies() 实际输出的 4 条独立命题，其中并没有「死亡 ⊥ SES | {Age, Severity, Statins, Exercise}」——因为 DAG 里有 SES -> Mortality 这条直接箭头，该独立性本来就不成立，数据当然「拒绝」它。用 d-分离的语言说：这条路径上的 SES→死亡直接边永远开放，任何调整集都阻断不了。所以正确做法是只检验 DAG 真正蕴含的独立性（dagitty 列出的那些），而不是随手挑一组条件。这个区分对医学研究者很重要：论文里写「我们检验了 DAG 的独立性含义，结果支持/不支持 DAG」时，检验的必须是 d-分离推出的命题。另一个原则：独立性检验只能证伪、不能证实（数据与多个 DAG 等价相容时无法区分），检验不显著不等于「DAG 被数据验证」；但检验显著一定是「有问题」的信号——可能是 DAG 画错、也可能是效应量估计的检验力问题，需要回到临床知识里找答案。

13.7 医疗应用的实用指南

在医疗研究中成功实施 DAG，需要在理论理想与现实条件之间取得平衡。在看数据之前，先基于临床知识勾勒出因果结构草图。这可以防止利用偶然模式（chance patterns）的事后修改。让临床专家、流行病学家和领域专家参与 DAG 的迭代式打磨。不同的视角常常能暴露个别研究者忽略的假设或通路。

把 DAG 聚焦于与具体因果问题相关的变量，而不是试图全面表示所有生物学关系。一个考察处理效应的 DAG，不必纳入每一条生理通路，只要这些机制不混淆所关注的关系。明确记录并论证所有因果假设。这种透明使读者能够评价他们是否认同提出的结构，并理解替代假设可能如何影响结论。

通过敏感性分析考虑多个合理的 DAG 结构。如果不同的合理因果结构导向相似的结论，研究发现就获得了稳健性。如果结论关键性地依赖于有争议的因果假设，要明确承认这种不确定性，并考虑能直接检验这些假设的设计。用 DAG 识别设计改进的机会。如果 DAG 显示多测量一个变量就能实质性加强因果识别，就在后续研究中优先收集它。

要认识到 DAG 代表的是假设而非发现。它们使既有的因果信念变得明确、可分析，但无法单凭观察性数据证明因果关系。其价值在于厘清「要把估计作因果解读，我们必须相信什么」，而不是提供确定的因果证明。

13.8 结论：DAG 是严谨因果推断的基石

有向无环图把因果推断从依赖未言明假设的非正式实践，转变为一个透明的分析框架——因果主张立足于明确、可评估的基础。通过迫使研究者在分析数据之前阐明他们对底层因果结构的看法，DAG 避免了利用虚假模式的临时调整，同时为「哪些变量需要测量和控制才能进行有效的因果推断」提供了清晰指引。

我们考察的医疗应用展示了 DAG 对研究设计与分析的实用价值。在他汀—死亡例子中，DAG 分析揭示了为什么朴素比较会产生误导性结论，识别出需要调整的最小变量集，并解释了为什么过度调整会制造新的偏倚。这些洞见直接服务于新研究的设计和现有数据的分析，提升了指导临床决策与卫生政策的因果主张的可靠性。

通过与 dagitty 和 ggdag 等现代统计软件的集成，严谨的 DAG 分析对应用研究者不再要求深厚的数学功底。这些工具自动完成调整集识别、生成可检验含义，并绘制能把因果假设有效传达给临床医生、政策制定者和期刊审稿人等多元受众的发表级图形。

也许最重要的是，DAG 通过让假设可见、可检验，为因果主张提供了智识上的谦逊。当我们明确承认「因果结论取决于未测混杂足够弱」或「某些因果通路存在/不存在」时，我们是在邀请批判性评价和敏感性分析，而不是呈现虚假的确定性。这种透明强化而非削弱了因果推断——它把争论聚焦于因果结构的实质问题，而非统计方法的技术细节。

随着我们从「描述关联」走向「推荐干预」，医疗研究的未来对严谨因果推断的要求与日俱增。DAG 为这一转变提供了必要的基础设施，使研究者能够设计出可信识别因果效应的研究、以尊重底层因果结构的方式分析数据、并以适当的分寸传达「从现有证据中我们能和不能得出什么」。对于致力于产生可改善患者照护和人群健康的因果知识的研究者，DAG 不是可选的技术工具，而是严谨因果思维的基本要求。
