第 11 章 用于因果推断的 g-计算

原书第 11 章 · g-computation-for-causal-inference.html · Kamran Afzali《Causal Inference in R》中文译本 · 非官方翻译

11.1 引言

一位 55 岁的高血压患者来门诊就诊。她目前正在服用一线降压药，而你正在考虑为她加用他汀以保护心血管。但这个决定并不简单——你需要考虑的不仅是他汀的直接效应，还有它可能如何与她的降压药相互作用、她的治疗依从性会如何变化，以及在不同治疗策略下她未来十年的心血管风险轨迹。传统临床试验给出的是人群平均效应，其适用人群可能与这位患者复杂的病情画像和治疗经历并不匹配。

这正是 g-计算（G-computation）大显身手的地方——它是因果推断中最强大却被利用不足的工具之一。g-计算由 Jamie Robins 于 20 世纪 80 年代提出，通过对数据生成过程进行显式建模，并利用这些模型模拟不同治疗策略（treatment regime）下的反事实（counterfactual）结局，为从观察性数据估计因果效应提供了一个通用框架。与聚焦于建模处理分配的倾向得分（propensity score）方法不同，g-计算直接对结局过程建模，因而能够在处理与混杂（confounder）随时间变化的复杂纵向场景中估计效应。

方法之名来自「G 公式」（G-formula）——一个通过对混杂因子分布做标准化（standardization）来获得边际因果效应的数学表达式。尽管其理论可能令人望而生畏，核心直觉却相当直白：如果我们能建立「在控制混杂的前提下，处理如何影响结局」的好模型，就能用这些模型预测在不同治疗策略下会发生什么。通过比较不同情景下的预测，我们无需依赖传统回归调整那种强参数假设，即可还原因果效应。

在其他因果方法力不从心的若干场景中，g-计算表现出色。它能处理时变处理（time-varying treatment）——即某一时间点的处理决策依赖于既往结局，这在临床医生依据患者病情演变调整用药的慢性病管理中十分常见。该方法天然支持中介分析，因为可以对位于处理与结局之间因果路径上的中间变量进行显式建模。它既能给出特定患者画像的条件效应，也能给出按人群特征平均的边际效应，灵活性足以匹配多样的研究问题。或许最重要的是，g-计算能够估计复杂动态治疗策略下的效应，而这类策略在随机试验中是不可能研究或不合伦理的。

g-计算的理论基础建立在潜在结局（potential outcomes）框架与 Pearl 的 do-演算之上，为把观察性关联转化为因果陈述提供了严格依据。考虑一个简单设定：处理 \(A\)、结局 \(Y\) 与基线混杂因子 \(L\)。在潜在结局框架下，每个个体都有潜在结局 \(Y^{a}\)，表示若其接受处理水平 \(a\) 时的结局。处理相对于不处理的因果效应为 \(\mathbb{E}[Y^{1} - Y^{0}]\)，但我们面对因果推断的根本问题：我们只能观测到 \(Y^{A}\)，即实际所接受处理下的结局。

G 公式给出了在可交换性（exchangeability，又称可忽略性 ignorability、无未测量混杂）假设下完成识别（identification）的关键。该假设断言：在给定已测量混杂因子 \(L\) 的条件下，处理分配独立于潜在结局，即对所有 \(a\) 有 \(Y^{a} \perp A \mid L\)。此外我们还需要正值性（positivity）：给定其混杂因子取值，每个个体接受任一处理水平的概率都为正，即对所有相关的 \(a\) 与 \(l\) 有 \(P(A = a \mid L = l) > 0\)。在这些假设下，G 公式把潜在结局的边际均值表示为 \(\mathbb{E}[Y^{a}] = \sum_{l} \mathbb{E}[Y \mid A = a, L = l] \cdot P(L = l)\)。

这个公式有一个优雅的解释：要计算「若所有人都接受处理 \(a\)」的平均结局，我们先算出在混杂因子的每一种模式下、接受处理 \(a\) 时的期望结局，再按人群中混杂因子的实际分布求平均。这种标准化通过使各处理组在混杂因子分布上可比，从而消除混杂。因果效应即不同处理取值下这些标准化均值之差：\(\mathbb{E}[Y^{1}] - \mathbb{E}[Y^{0}]\)。

背景与解释

g-计算与流行病学里的「标准化」是一脉相承的。单时点、单处理的 G 公式，本质上就是对结局模型 \(\mathbb{E}[Y \mid A, L]\) 做直接标准化：把每个人在「若接受处理」下的预测值算出来，再对人群求平均。这与计算标准化死亡率比（SMR）时用标准人口构成加权各层率、或计算 Mantel–Haenszel 合并 OR 时按层加权，思路完全相同，只是 g-计算把这一操作推广到了多时点、时变处理的一般情形。Robins 1986 年的原始论文标题就叫「A new approach to causal inference in mortality studies with sustained exposure periods」，服务对象正是职业流行病学中的「持续暴露」问题。对临床研究者而言，记住这一点很有用：g-计算并不是什么神秘的新机器学习，而是标准化思想在复杂数据上的彻底执行。

G 公式可以自然推广到处理与混杂皆时变的纵向场景：治疗史会影响未来的混杂因子，而混杂因子又反过来影响未来的处理决策。这就造成了时依混杂（time-dependent confounding），它违反了标准回归调整的假设。考虑一系列处理决策 \(A_0, A_1, \ldots, A_K\)，以及在每次处理决策前测量的时变混杂因子 \(L_0, L_1, \ldots, L_K\)，最终结局 \(Y\) 在时间 \(K+1\) 测量。对于治疗策略 \(\bar{a} = (a_0, a_1, \ldots, a_K)\)，纵向 G 公式变为

\[\mathbb{E}[Y^{\bar{a}}] = \sum_{\bar{l}} \mathbb{E}[Y \mid \bar{A} = \bar{a}, \bar{L} = \bar{l}] \prod_{k=0}^{K} P(L_k = l_k \mid \bar{A}_{k-1} = \bar{a}_{k-1}, \bar{L}_{k-1} = \bar{l}_{k-1})\]

这个令人生畏的表达式刻画了纵向数据的序列本质：既往的处理与混杂会影响未来协变量的演化。公式对一切可能的混杂因子轨迹做边缘化，并按目标治疗策略下每条轨迹的概率加权。尽管精确计算需要对所有可能的协变量历史求和（实际上计算上不可行），我们可以通过参数建模与蒙特卡洛（Monte Carlo）模拟来近似这个期望。

参数化 G 公式算法通过三个基本步骤把数学公式转化为实用的计算流程：模型设定、蒙特卡洛模拟与效应估计。该方法要求为「处理如何影响结局」以及「处理与既往历史如何影响未来混杂因子」分别设定参数模型，然后利用这些模型模拟不同治疗策略下的反事实轨迹。

在模型设定阶段，我们为每个时变成分分别构建回归模型。对结局，我们把 \(\mathbb{E}[Y \mid \bar{A}, \bar{L}]\) 建模为处理史与混杂因子史的函数，通常使用与结局类型相匹配的广义线性模型。对每个时变混杂因子 \(L_k\)，我们建模 \(P(L_k \mid \bar{A}_{k-1}, \bar{L}_{k-1})\)，以捕捉既往处理与协变量如何影响未来的协变量取值。这些模型体现了我们对数据生成过程的理解，无需在所有细节上都正确——只需足够准确地刻画处理、混杂与结局之间的关系，从而给出无偏的效应估计即可。

蒙特卡洛模拟阶段在不同治疗策略下生成反事实数据集。从每个个体观测到的基线协变量 \(L_0\) 出发，我们按时间向前模拟：先赋予指定的处理取值 \(a_0\)，再用拟合好的混杂因子模型在给定 \(a_0\) 与 \(L_0\) 的条件下模拟 \(L_1\)，如此推进直至所有时间点。对每一个感兴趣的治疗策略，这一过程都会生成一份完整的反事实数据集，其中每个个体都遵循同一套治疗策略。通过模拟每种治疗策略下混杂因子的自然演化，我们造出了在随机试验中本应可交换的合成比较组。

最后，把结局模型分别拟合到每份模拟数据集上并对所有个体的预测取平均，即可估计每种策略下的结局。因果效应就从这些策略特异（regime-specific）的结局估计的比较中浮现。若要得到同时反映抽样波动与模型估计不确定性的置信区间，需要自助重采样（bootstrap resampling）：在原始数据的自助样本上重复整个流程，以量化估计的不确定性。

11.2 案例研究：长期高血压管理

我们将通过一个贴近现实的场景来探索 g-计算：高血压管理，其中处理强度时变，心血管风险不断演化。我们的目标是估计持续强化降压相对于标准降压对五年心血管事件风险的影响，同时纳入基于患者状态演化的治疗调整。

这个模拟捕捉了高血压管理的若干真实特征：依据血压水平与危险因素强化治疗、影响疗效的非完美依从性、依赖治疗与依从模式的血压演化，以及受当前血压、治疗与基线危险因素共同影响的心血管事件。时依混杂会自然浮现：时间 \(t\) 的血压既影响时间 \(t\) 的治疗决策，也影响时间 \(t+1\) 的结局，而既往治疗又会影响当前血压。

背景与解释

时依杂因为什么难倒传统方法？设想用一锅端的多元回归同时调整基线变量和每次随访的血压。问题是随访期的血压本身就是既往处理的结果（处理→血压→后续处理→结局），它在因果图上既不是纯粹的混杂因子，也不是纯粹的中介。把这类变量当混杂因子调整，相当于在一条因果路径上「过度控制」（over-control），可能引入对撞偏倚（collider bias）或屏蔽掉真实效应——Robins 称之为「调整了坏控制变量」（bad control）。这正是为什么在观察性纵向数据中，他汀、依从性、血压这类彼此纠缠的变量不能简单地「全部塞进回归」：g-计算的策略是给每个变量建各自的模型，再按时间顺序正向模拟，让因果次序自动归位。

simulate_hypertension_data <- function(n = 1000, time_points = 6) {
  
  # 基线特征
  baseline <- data.frame(
    id = 1:n,
    age = rnorm(n, 55, 8),
    diabetes = rbinom(n, 1, 0.3),
    smoking = rbinom(n, 1, 0.25),
    baseline_sbp = rnorm(n, 145, 15)
  )
  
  # 预分配长度正确的列表
  long_data <- vector("list", n)
  
  for (i in 1:n) {
    # 个体基线取值
    sbp <- baseline$baseline_sbp[i]
    treatment <- 0
    adherence <- 1
    
    # 预分配数据框
    individual_data <- data.frame(
      id = rep(baseline$id[i], time_points),
      time = 0:(time_points - 1),
      age = rep(baseline$age[i], time_points),
      diabetes = rep(baseline$diabetes[i], time_points),
      smoking = rep(baseline$smoking[i], time_points),
      sbp = numeric(time_points),
      treatment = numeric(time_points),
      adherence = numeric(time_points),
      cvd_event = numeric(time_points),
      event_time = rep(NA, time_points)
    )
    
    cvd_event_occurred <- FALSE
    event_time <- NA
    
    for (t in 0:(time_points - 1)) {
      # 记录当前状态
      individual_data$sbp[t + 1] <- sbp
      individual_data$treatment[t + 1] <- treatment
      individual_data$adherence[t + 1] <- adherence
      
      # 心血管事件（仅新发事件）
      if (!cvd_event_occurred) {
        event_prob <- plogis(-8 + 0.04 * sbp + 0.05 * baseline$age[i] + 
                               0.8 * baseline$diabetes[i] + 0.6 * baseline$smoking[i] - 
                               0.5 * treatment * adherence)
        cvd_event_occurred <- rbinom(1, 1, event_prob) == 1
        
        if (cvd_event_occurred) {
          event_time <- t
        }
      }
      
      # 记录事件（新发事件；建模时不作为吸收态）
      individual_data$cvd_event[t + 1] <- as.integer(cvd_event_occurred && t == event_time)
      individual_data$event_time[t + 1] <- event_time
      
      # 为下一个时间点更新变量
      if (t < time_points - 1) {
        # 处理决策（基于既往血压与危险因素）
        treatment_prob <- plogis(-2 + 0.03 * sbp + 0.5 * baseline$diabetes[i] + 
                                   0.3 * baseline$smoking[i])
        treatment <- rbinom(1, 1, treatment_prob)
        
        # 依从性（受处理强度影响）
        adherence_mean <- plogis(1 - 0.5 * treatment + 0.01 * (sbp - 120))
        # 做变换以避免 beta 回归的边界问题
        adherence <- pmin(0.99, pmax(0.01, rnorm(1, adherence_mean, 0.15)))
        
        # 更新收缩压（受处理与依从性影响）
        treatment_effect <- -12 * treatment * adherence
        sbp <- 0.7 * sbp + 0.3 * baseline$baseline_sbp[i] + 
          treatment_effect + rnorm(1, 0, 5)
        sbp <- pmax(90, pmin(200, sbp))
      }
    }
    
    long_data[[i]] <- individual_data
  }
  
  # 合并所有个体数据
  data <- rbindlist(long_data)
  setorder(data, id, time)
  
  return(as.data.frame(data))
}

fit_confounder_models <- function(data) {
  # 收缩压模型（连续型结局）
  cat("Fitting SBP model...\n")
  sbp_model <- lm(sbp ~ sbp_lag + treatment + treatment_lag + 
                    adherence + adherence_lag + diabetes + smoking + age + time,
                  data = data[data$time > 0, ])
  
  # 依从性模型（有界连续结局用 beta 回归）
  cat("Fitting adherence model...\n")
  # beta 回归要求取值在 (0,1) 内，不能触及边界
  adherence_data <- data[data$time > 0 & data$adherence > 0 & data$adherence < 1, ]
  adherence_model <- betareg(adherence ~ treatment + sbp_lag + diabetes + time,
                             data = adherence_data)
  
  # 结局模型（新发事件用 logistic 回归）
  cat("Fitting CVD outcome model...\n")
  # 仅对新发事件建模（不作为吸收态）
  outcome_model <- glm(cvd_event ~ sbp + treatment + adherence + 
                         age + diabetes + smoking + time,
                       data = data, 
                       family = binomial())
  
  cat("\nModel diagnostics:\n")
  cat("SBP model R-squared:", round(summary(sbp_model)$r.squared, 3), "\n")
  cat("Adherence model pseudo R-squared:", round(adherence_model$pseudo.r.squared, 3), "\n")
  cat("Outcome model AIC:", round(AIC(outcome_model), 1), "\n")
  
  list(
    sbp = sbp_model, 
    adherence = adherence_model, 
    outcome = outcome_model,
    sbp_sigma = sigma(sbp_model)
  )
}

背景与解释

g-计算与 IPTW/MSM 是观察性因果推断的三大主力，常被拿来比较。简单地说：IPTW 建模「谁接受了处理」，通过加权构造伪人群；MSM（边际结构模型）给加权后的数据拟合一个边际（如对数线性）模型，得到风险比等参数化效应；g-计算 建模「结局如何发生」，通过标准化直接得到各策略下的边际风险。在同样的识别假设（无未测量混杂、正值性、一致性）下，三者估计的是同一个目标量，大样本下应给出一致答案；差别在于对小样本的表现、对模型误设定的敏感方向、以及能自然呈现的估计对象不同。实践中常把 IPTW 与 g-计算结合成双稳健（doubly robust）估计：结局模型或处理模型有一个正确即可。对临床研究者，一个实用的记忆法是：想报告「每人五年风险」这类绝对量、或要模拟动态策略，g-计算最直接；想报告「风险比」且处理很少（权重更稳），IPTW/MSM 可能更顺手。

11.2.1 拟合 G 公式模型

gfoRmula 包提供了参数化 G 公式算法的完整实现，内置自助推断与诊断工具。关键难点在于正确设定时变混杂因子与结局的模型：既要捕捉依赖结构，又要避免过拟合。

模型设定需要仔细斟酌哪些变量能预测混杂因子演化和结局。对收缩压，我们纳入滞后值以刻画持续性，纳入当前治疗与依从性以捕捉治疗效果，并纳入可能影响血压轨迹的基线危险因素。依从性模型捕捉处理强度与感知风险（通过滞后血压）如何影响患者的坚持程度。结局模型同时纳入当前血压与治疗，从而允许处理的效应既通过降血压、也可能通过其他路径发挥作用。

simulate_counterfactual_mc <- function(data, models, treatment_strategy, 
                                       n_simulations = 500, verbose = TRUE) {
  
  baseline_data <- data[data$time == 0, ]
  n_subjects <- nrow(baseline_data)
  
  # 跨模拟存储结果
  all_risks <- matrix(NA, nrow = n_simulations, ncol = 6)
  all_cumulative_incidence <- numeric(n_simulations)
  
  for (sim in 1:n_simulations) {
    if (verbose && sim %% 100 == 0) cat("  Simulation", sim, "of", n_simulations, "\n")
    
    sim_data <- baseline_data
    sim_data$treatment <- treatment_strategy(sim_data, 0)
    sim_data$cvd_event_sim <- 0
    sim_data$event_occurred <- FALSE
    
    for (t in 1:5) {
      prev_data <- sim_data[sim_data$time == t - 1, ]
      
      # 为时间 t 创建新数据
      new_data <- prev_data
      new_data$time <- t
      new_data$treatment_lag <- prev_data$treatment
      new_data$sbp_lag <- prev_data$sbp
      new_data$adherence_lag <- prev_data$adherence
      
      # 按策略分配处理
      new_data$treatment <- treatment_strategy(new_data, t)
      
      # 模拟依从性
      adherence_pred <- predict(models$adherence, newdata = new_data, type = "response")
      adherence_noise <- rnorm(nrow(new_data), 0, 0.1)
      new_data$adherence <- pmin(0.99, pmax(0.01, adherence_pred + adherence_noise))
      
      # 模拟收缩压
      sbp_pred <- predict(models$sbp, newdata = new_data)
      new_data$sbp <- sbp_pred + rnorm(nrow(new_data), 0, models$sbp_sigma)
      new_data$sbp <- pmin(200, pmax(90, new_data$sbp))
      
      # 模拟心血管事件（仅针对尚未发生事件的个体）
      cvd_prob <- predict(models$outcome, newdata = new_data, type = "response")
      new_event <- rbinom(nrow(new_data), 1, cvd_prob)
      
      # 仅计入新发事件
      new_data$cvd_event_sim <- ifelse(!prev_data$event_occurred, new_event, 0)
      new_data$event_occurred <- prev_data$event_occurred | (new_event == 1)
      
      sim_data <- rbind(sim_data, new_data)
    }
    
    # 计算本次模拟中各时间点的风险
    for (t in 0:5) {
      all_risks[sim, t + 1] <- mean(sim_data[sim_data$time == t, "event_occurred"])
    }
    
    # 随访期末的累积发生率
    all_cumulative_incidence[sim] <- mean(sim_data[sim_data$time == 5, "event_occurred"])
  }
  
  list(
    mean_risk_trajectory = colMeans(all_risks),
    risk_trajectory_se = apply(all_risks, 2, sd),
    cumulative_incidence = mean(all_cumulative_incidence),
    cumulative_incidence_se = sd(all_cumulative_incidence),
    all_cumulative_incidence = all_cumulative_incidence
  )
}

  always_treat = function(data, time) rep(1, nrow(data)),

背景与解释

这个案例值得从生存分析的角度挑出两点讨论。其一，模拟把心血管事件当作「吸收态」处理（发生后不再产生新事件，event_occurred 一旦为真便锁定），这符合临床现实；但结局模型本身是逐期的 logistic 回归，累积发生率由各期风险拼接而成，而不是用 Kaplan–Meier 或 Cox 模型直接对事件时间建模。在真实数据中，若存在竞争风险（如非心血管死亡）或删失，逐期 logistic 会低估事件率、且无法给出风险比的时间解释——规范的纵向生存分析需要把每期的「存活 × 未删失」状态显式纳入 g-计算（Robins 的纵向生存 G 公式），或先做 IPTW 再加权 Cox 模型。其二，本模拟中基线期事件率高达 69.7%，在真实世界里应对应「极短随访窗口内的事件」，读者不必对绝对值较真，重点是理解方法流程。

# 计算风险差与风险比（含自助置信区间）的函数
calculate_effect <- function(results, reference, comparator) {
  ref_samples <- results[[reference]]$all_cumulative_incidence
  comp_samples <- results[[comparator]]$all_cumulative_incidence
  
  risk_diff <- ref_samples - comp_samples
  risk_ratio <- ref_samples / comp_samples
  
  list(
    risk_diff_mean = mean(risk_diff),
    risk_diff_ci = quantile(risk_diff, c(0.025, 0.975)),
    risk_ratio_mean = mean(risk_ratio),
    risk_ratio_ci = quantile(risk_ratio, c(0.025, 0.975))
  )
}

11.2.2 结果解读与模型诊断

G 公式估计通过比较不同策略下的反事实风险，揭示持续治疗策略的因果效应。关键估计量包括：每种治疗策略下的风险（若所有患者都遵循该策略，五年内发生心血管事件的概率）、量化强化治疗绝对风险下降的风险差，以及提供治疗获益相对尺度的风险比。

除点估计外，我们还必须通过诊断程序评估模型的充分性。gfoRmula 包提供了若干工具，用于评估参数模型是否充分刻画了数据生成过程。每个协变量模型的拟合优度统计量提示我们是否正确设定了函数形式、是否纳入了相关预测变量。平衡性检查则比较「自然病程」下模拟的协变量分布与观测分布——巨大差异意味着模型误设定。

「自然病程」下观测与模拟血压轨迹的良好吻合，为协变量模型充分捕捉时变混杂因子过程提供了证据。若出现实质性偏离，则提示需要修改函数形式、加入交互项或纳入额外预测变量。策略特异风险周围的置信区间反映自助不确定性，同时涵盖了抽样波动与拟合模型的估计误差。

11.3 实际考量与局限性

g-计算真正的威力，展现在估计那些随时间适应患者状态的动态治疗策略（dynamic treatment regime）效应之时——它模拟的正是临床真实决策：是否强化治疗取决于患者不断演变的特征。静态策略在基线一次性指定处理，而动态策略把处理规则设定为观测历史的函数。

动态策略能回答一系列临床相关问题：按血压阈值治疗是否优于全员治疗？不同患者亚组应以什么阈值触发强化？实施基于阈值的治疗规则需要多密的监测？G 公式通过模拟不同决策规则下血压如何演化并计算相应的事件率，自然而然地容纳了这类问题。

成功实施 g-计算需要注意若干决定其能否给出有效因果估计的实际问题。模型设定是最关键的挑战，因为方法的有效性依赖于正确处理、混杂与结局之间的关系。与倾向得分方法对结局模型误设定具有一定稳健性不同，g-计算要求结局模型与协变量模型都足够准确。不过，这一要求并没有看上去那么苛刻——模型无需完美设定，但必须捕捉变量间的基本关系。通常，纳入相关交互项、非线性项与滞后变量就足以获得合格的表现。

背景与解释

两条实务建议送给准备上手的研究者。第一，正值性要在数据里先检查：如果某个协变量组合下所有人都接受了同一处理（例如「高龄 + 多种合并症 + 低血压」的患者从来不会被强化治疗），该格子里就没有反事实信息，g-计算只能做外推；此时应合并稀疏层、截断极端权重或限制目标人群。第二，对未测量杂总不能止步于「我们假设没有」：可以报告 E-value（使结论翻转所需的未测量混杂的最小关联强度）、或运行阴性对照结局/阴性对照暴露分析。原书提到「敏感性分析提供背景」但未展开，E-value 计算简单（一个公式）、视觉直观，很适合作为观察性因果论文的标准附录。

样本量问题在纵向场景中格外重要，因为我们必须为每个时变协变量单独拟合模型。小样本可能给不出稳定估计，尤其在处理模式稀疏或协变量分布随时间大幅变化时。一条粗略的经验法则：纵向 g-计算至少需要数百名随访完整的受试者才能提供可靠估计，尽管确切要求取决于数据生成过程的复杂程度与时间点数量。

无未测量混杂这一根本假设无法被经验验证，它需要关于数据生成过程的实质知识。在观察性高血压研究中，患者偏好、医生的诊疗风格、健康行为等未测量因素可能同时影响治疗决策与心血管结局。考察结果在不同程度未测量混杂下如何变化的敏感性分析，能为因果结论提供重要背景，但 g-计算本身并不能解决未测量变量带来的混杂。

在时间点与协变量众多的纵向场景中，自助推断的计算开销可能相当可观。每一轮自助迭代都需要重新拟合全部协变量模型与结局模型，然后在每种治疗策略下模拟所有受试者的反事实轨迹。并行计算能大幅缩短时间，但对于配有足量自助样本的复杂分析，研究者仍应预期以「小时」而非「分钟」计的耗时。

模型相容性是实践中另一个常被忽视的问题。当协变量模型与结局模型对数据生成过程作出互不相容的假设时，即使单个模型看起来设定良好，G 公式估计仍可能有偏。例如，若血压模型假设时间趋势是线性的，而结局模型纳入非线性的时间效应，模拟出的反事实轨迹就可能无法准确反映结局在不同治疗策略下的演化方式。确保模型间的一致性，需要对函数形式与所纳入协变量仔细斟酌。

近期方法学进展把 g-计算扩展到日益复杂的场景，拓展了它的实用版图。双稳健（doubly robust）估计把 g-计算与逆概率加权（inverse probability weighting, IPW）相结合：只要结局模型或处理模型之一设定正确，就能给出一致估计。这一方法提供了纯基于模型的 g-计算所不具备的误设定保护，代价是计算复杂度上升，且置信区间可能更宽。

机器学习的 g-计算用随机森林、梯度提升、神经网络等灵活算法取代参数模型。这些方法无需显式设定即可捕捉复杂的非线性关系与交互，当真实数据生成过程与参数假设相去甚远时，表现可能更好。但机器学习的 g-计算需要认真对待过拟合，在中等样本量下估计的稳定性可能下降，可解释性也不及参数方法。

背景与解释

把这一节放进更大的方法学版图：当代实践常把 g-计算与 SuperLearner 集成（把多个候选模型堆叠成「超级学习器」自动挑权重）结合，用数据而非研究者先验来决定模型形式；若同时引入交叉拟合（cross-fitting）与 Neyman 正交性，就得到「双重机器学习（DML）」式的估计，在扰动函数可微、样本量适中时兼得稳健与高效。TMLE 则可视为 g-计算的「迭代加权升级版」。对这些方法，一个中肯的提醒是：它们放宽的是「函数形式误设定」，而非「未测量混杂」——识别假设永远无法靠算法补救。

靶向极大似然估计（targeted maximum likelihood estimation, TMLE）通过同时利用结局模型与处理模型的信息，提供了标准 g-计算之外的一种更高效选择。该方法用精巧的加权方案更新初始的基于模型的估计，从而降低偏倚、提高精度。在对效率要求极高的场景中，TMLE 在流行病学与生物统计学中日益受到青睐，尽管其实现复杂度高于标准 g-计算。

中介分析是 g-计算的天然应用场景，因为该方法对中间变量的显式建模使总效应可被分解为直接通路与间接通路。以高血压管理为例，我们可以把治疗效应分解为不经由降压介导的直接效应，与通过血压控制起作用的间接效应。这类分解为「治疗如何产生效应」提供了机制性洞见，有助于开发更有效的干预。

11.4 结论：把 g-计算融入实践

g-计算为从观察性数据开展因果推断提供了一个强大而灵活的框架，在处理与混杂时变、传统方法举步维艰的纵向场景中尤为出色。该方法对数据生成过程的显式建模，使其能够估计复杂治疗策略下的效应，同时给出关于治疗如何随时间影响结局的、可解释的洞见。

我们的高血压案例演示了使用 gfoRmula 包的实践流程：如何设定合适的模型、模拟反事实轨迹、并以临床上有意义的方式解读结果。比较静态与动态治疗策略的能力，使我们能够直接回答这样的临床决策问题：对风险画像不断演变的患者，何时治疗、治疗到什么强度。

成功的应用需要仔细对待模型设定、充足的样本量，以及通过诊断程序验证建模假设。当研究者对数据背后的因果结构拥有扎实的领域知识、并能设定出捕捉处理—混杂—结局基本关系的模型时，该方法的表现最佳。尽管 g-计算比某些替代方法需要更多的前期建模投入，它会以「符合临床实际决策方式的治疗策略下的因果效应估计」回报这份投入。

g-计算与现代计算工具、机器学习方法的结合，正在不断拓展复杂纵向数据因果推断的边界。随着医疗卫生越来越依赖观察性电子病历与登记数据来支持治疗决策，像 g-计算这样能从这类数据中提炼有效因果结论的方法，正成为循证医学与精准医疗的必备工具。
