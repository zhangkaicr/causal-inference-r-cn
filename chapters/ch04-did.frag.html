4.1 引言

在观察性研究中，随机对照试验（randomized controlled trial, RCT）往往不可行，此时像双重差分（difference-in-differences, DiD）这样的因果推断方法，就能在特定假设下为估计处理效应（treatment effect）提供一个稳健的框架。DiD 在拥有面板数据（panel data）的场景中尤其有价值——同一批观察单位被连续追踪多个时间点，其中一部分接受处理，另一部分不接受。借助数据的时间结构，DiD 通过比较处理组与对照组随时间发生的结局（outcome）变化，把处理的因果效应分离出来。该方法被广泛应用于经济学、公共政策和医疗卫生等领域，用于评估政策变动、医疗项目一类的干预。

本文聚焦 DiD，探讨它的理论基础、数学形式与实践实现。我们配合 R 代码，用一个贴近现实的医疗案例——评估远程医疗（telemedicine）项目对患者结局的影响——来演示这套方法。我们还将讨论诊断方法、局限性与各种扩展，以保证因果推断的稳健性。

背景与解释

在卫生政策评估中，DiD 是最常用的准实验设计之一。典型场景如：某省率先推行按病种付费（DRG）改革、某医院集团分批次上线抗菌药物管理系统、某市对部分社区试点家庭医生签约服务——政策不可能随机分配到人或医院，但可以按机构、按地区、按时间分批推开，这就天然形成了「处理组」与「对照组」以及「处理前」与「处理后」。流行病学读者可以把 DiD 理解为一种「利用政策试点做自然实验」的思路：它不做个体层面的配对，而是利用群体层面的时间趋势差异来识别效应。与 RCT 相比，DiD 的优势是不受伦理与可行性限制、能直接评估真实世界中的政策；代价是依赖平行趋势假设，且估计的是试点人群的效应，向其他人群外推需谨慎。

4.2 双重差分：理论框架

4.2.1 核心思想

DiD 通过比较处理组与对照组结局随时间的变化来估计处理的因果效应。该方法假设：如果没有处理，处理组与对照组的结局会遵循平行趋势（parallel trends）。这一假设使 DiD 能够同时排除两类干扰：组间不随时间变化的差异（例如两组患者基线病情轻重不同），以及同时影响两组的共同时间趋势（例如全国范围内诊疗规范的变化）。

4.2.2 数学形式

下面把 DiD 框架形式化。对单位 \(i\) 在时间 \(t \in \{0, 1\}\)（处理前与处理后）定义如下符号：

  • \(Y_{it}\)：单位 \(i\) 在时间 \(t\) 的观测结局。
  • \(D_i \in \{0, 1\}\)：处理指示变量（\(D_i = 1\) 表示处理组单位，\(D_i = 0\) 表示对照组单位）。
  • \(T_t \in \{0, 1\}\)：时间指示变量（\(T_t = 0\) 表示处理前，\(T_t = 1\) 表示处理后）。
  • \(Y_{it}(1), Y_{it}(0)\)：分别在接受处理与未接受处理下的潜在结局（potential outcomes）。

我们关心的因果效应是处理组平均处理效应（average treatment effect on the treated, ATT）：

\[ \text{ATT} = \mathbb{E}[Y_{i1}(1) - Y_{i1}(0) \mid D_i = 1] \]

DiD 估计量假设观测结局可以建模为：

\[ Y_{it} = \beta_0 + \beta_1 D_i + \beta_2 T_t + \delta (D_i \cdot T_t) + \epsilon_{it} \]

其中：

  • \(\beta_0\)：对照组在处理前（\(t = 0\)）的基线结局。
  • \(\beta_1\)：处理组与对照组之间不随时间变化的差异。
  • \(\beta_2\)：同时影响两组的共同时间趋势。
  • \(\delta\)：DiD 估计量，即 ATT 的估计。
  • \(\epsilon_{it}\)：误差项，假设均值为零。

DiD 估计量按下式计算：

\[ \widehat{\text{DiD}} = \left( \bar{Y}_{1, \text{treated}} - \bar{Y}_{0, \text{treated}} \right) - \left( \bar{Y}_{1, \text{control}} - \bar{Y}_{0, \text{control}} \right) \]

其中 \(\bar{Y}_{t, g}\) 是组 \(g\)（处理组或对照组）在时间 \(t\) 的平均结局。

4.2.3 关键假设：平行趋势

DiD 的有效性取决于平行趋势假设：

\[ \mathbb{E}[Y_{i1}(0) - Y_{i0}(0) \mid D_i = 1] = \mathbb{E}[Y_{i1}(0) - Y_{i0}(0) \mid D_i = 0] \]

它假设：若没有处理，处理组的平均结局变化应当等于对照组的平均结局变化。由于处理组在治疗后的反事实结局 \(Y_{i1}(0)\) 不可观测，这一假设无法被直接检验；但我们可以通过考察处理前的趋势、或纳入协变量调整潜在混杂因子，来评估其合理性。

  • 数据要求：DiD 需要面板数据（同一批单位被重复观测）或具有清晰处理组与对照组的重复截面数据。
  • 协变量：纳入不受处理影响的控制变量，可以提高精度并调整时变混杂因子。
  • 诊断：应当可视化处理前的趋势以评估平行趋势假设；安慰剂检验（placebo test）等稳健性检查可以进一步验证模型。
  • 扩展：DiD 可以扩展到多个时间期、交错采纳处理（staggered treatment adoption）或异质性效应的情形，使用广义 DiD 等高级方法。
背景与解释

平行趋势假设在临床场景中的含义值得细说。它并不要求两组患者的病情完全相同，而只要求：在没有干预的情况下，两组结局指标会以相同的方式随时间漂移。例如比较开展远程医疗的诊所与未开展的诊所的再入院率，只要两组周边没有发生只影响其中一方的变化（如一家连锁药店只在处理组社区开业、一场流感只冲击其中一个病区），共同的时间漂移就可以被差分掉。临床研究中常见的违反情形包括：处理组与对照组位于不同地区而地区政策不同、处理组医院同期还开展了其他质量改进项目、疾病谱变化对两组影响不对称。选择对照组时，应优先寻找与研究组患者结构相似、所处市场环境相似、且尚未开展该项目的机构；并在论文中报告两组处理前多个时间点的趋势图，这是 DiD 论文的「标配」证据。

4.3 应用：评估医疗领域的远程医疗项目

假设一家医疗集团于 2024 年推行远程医疗项目，以改善患者结局，例如降低慢性病患者的医院再入院率。项目在部分诊所（处理组）上线，其余诊所继续常规面对面诊疗（对照组）。我们观测患者结局（如 30 天再入院率）在 2023 年（处理前）与 2025 年（处理后）的表现。利用 DiD，我们估计该项目对再入院率的因果效应。

我们模拟 200 家诊所（100 家处理、100 家对照）两年间的再入院率数据。真实的处理效应为使再入院率下降 3%。我们纳入一个协变量（患者平均年龄）以控制潜在的混杂。

4.3.1 R 实现

下面的 R 代码用于模拟数据、估计 DiD 效应并执行诊断。

# 加载所需的 R 包
library(ggplot2)
library(dplyr)

# 设置随机种子以保证结果可复现
set.seed(123)

# 参数设定
n_clinics <- 200  # 100 家处理组诊所、100 家对照组诊所
time_periods <- 2  # 2023（处理前）、2025（处理后）
true_effect <- -5  # 效应量放大到 -5%，使效果更明显
noise_sd <- 0.5    # 减小噪声，使效应更容易被检测到

# 构建数据
data <- data.frame(
  clinic = rep(1:n_clinics, each = time_periods),
  time = rep(c(0, 1), times = n_clinics),  # 0 = 2023 年，1 = 2025 年
  year = rep(c(2023, 2025), times = n_clinics),
  treated = rep(rep(c(0, 1), each = time_periods), times = n_clinics/2),
  age = rep(rnorm(n_clinics, mean = 65, sd = 5), each = time_periods)
)

# 生成再入院率（%）
data$readmission <- 20 +                   # 基线再入院率
  1 * data$treated +                      # 处理组诊所的基线再入院率更高
  2 * data$time +                         # 长期世俗趋势
  true_effect * data$treated * data$time + # 处理效应
  0.1 * data$age +                        # 年龄效应
  rnorm(nrow(data), mean = 0, sd = noise_sd)  # 减小后的噪声

# 预览数据

背景与解释

本节用模拟数据来演示方法，这在方法学章节中很常见：因为「真实效应」已知，可以检验估计量是否工作。注意正文写的是真实效应为再入院率下降 3%，而代码中 true_effect <- -5，随后输出的估计值也约为 -5.1——以代码为准即可理解为示例参数，读者复现时不必纠结两个数字的不一致。另外要提醒两点：其一，这里的观测单位是诊所（聚类），同一诊所两年的再入院率相关，且两家诊所之间也可能相关，正式分析应使用聚类稳健标准误（以诊所为聚类单位）；其二，再入院率是介于 0 与 1 之间的比例，若直接对率本身做线性回归可能出现拟合值越界或异方差问题，实践中可考虑对数变换、logit 变换或以「再入院人数/出院人数」做 Poisson / 二项回归，再用边际效应解释。原书使用线性模型是为了让 DiD 的「交互项系数 = 效应」这一核心直觉保持透明。

# 手动计算 DiD
means <- data %>%
  group_by(treated, time) %>%
  summarise(readmission = mean(readmission), .groups = "drop")

y0_control <- means$readmission[means$treated == 0 & means$time == 0]
y1_control <- means$readmission[means$treated == 0 & means$time == 1]
y0_treated <- means$readmission[means$treated == 1 & means$time == 0]
y1_treated <- means$readmission[means$treated == 1 & means$time == 1]

did_estimate <- (y1_treated - y0_treated) - (y1_control - y0_control)
cat("DiD Estimate:", did_estimate, "%\n")
## DiD Estimate: -5.078044 %

输出解读：不借助回归，直接用四个组均值做差，得到的 DiD 估计为 -5.078044%，与回归中交互项的系数完全一致。这验证了两者等价：两期两组的 DiD 就是「处理组前后差」减去「对照组前后差」。

背景与解释

安慰剂检验（placebo test）的逻辑是「在没有处理的地方找处理」：随机或系统地更换假处理时点、假处理组，如果估计屡屡显著，说明差异来自趋势背离而非干预本身。事件研究法（event study）是它的「加强版」：把每一年都与基线年做交互，画出各期的系数轨迹，既能看处理前的趋势是否平行（处理前系数应贴近 0），又能看效应是否逐期累积、有无预期效应（anticipation，处理前系数就显著上翘）或衰减。两者是当今卫生政策评估论文的常规配置。近年计量经济学还提醒：当不同单位在不同时间采纳处理（交错采纳）时，用传统两期 DiD 或双向固定效应模型会把已经处理的单位悄悄用作对照组，产生「负权重」导致的偏倚；此时应使用 Callaway–Sant'Anna、Sun–Abraham 或 de Chaisemartin–D'Haultfœuille 等专门估计量。原书在「扩展」中提到的 staggered adoption 值得按这个方向深化。

4.3.2 局限性与要点

  • 处理前趋势：该图检查处理组与对照组诊所的再入院率在 2023 年之前是否遵循平行趋势，以支持平行趋势假设。
  • DiD 估计：交互项（\(\text{treated} \cdot \text{time}\)）上的回归系数在调整患者年龄后估计处理效应，手动计算确认了这一估计。
  • 安慰剂检验：把 DiD 应用于处理前年份（2022 对 2023）应得到不显著的效应，从而强化平行趋势假设的有效性。

在我们的模拟中，估计出的效应接近真实效应（-3%），表明远程医疗项目使再入院率下降了约 3 个百分点。

  • 违反平行趋势：若处理前趋势发生分化，DiD 估计可能有偏。合成控制法（synthetic control）或三重差分（triple differences）等技术可以应对这一问题。
  • 时变混杂因子：在两组间差异性地变化的未观测因素（例如新出台的医疗政策）可能使结果产生偏倚。纳入相关协变量可以缓解这一问题。
  • 外推性：ATT 适用于处理组人群。向其他人群推广需要谨慎。
  • 扩展：对于处理时点交错或多个时期的情形，可以使用广义 DiD 模型或固定效应回归。
背景与解释

DiD 与 RCT 的取舍是临床研究者最常面对的问题。当干预已知有益、需要快速回答、且混杂结构简单时，RCT 仍是金标准；DiD 更合适的场景是：随机化不可行（政策只能分批推开）、需要评估真实世界落地效果、或结局罕见且随访极长（如五年死亡率）时。一个常被忽视的点是，DiD 与 RCT 并不互斥——「阶梯式整群随机试验」（stepped-wedge cluster RCT）本质上就是随机化的交错采纳设计，既保留了随机化的无混杂保证，又能用 DiD 类估计量分析。反过来，如果处理组与对照组在年龄、病情等基线特征上差异很大，仅靠平行趋势并不够：可以在回归中纳入组别与时变协变量的交互，或先做倾向得分匹配/加权再做 DiD（即「匹配 + DiD」），让两组在处理前轨迹上更可比。

4.4 结论

双重差分是一种强大的准实验因果推断方法，在随机试验不可行的医疗场景中尤为实用。借助面板数据与平行趋势假设，DiD 以直观而有吸引力的方式分离出处理效应。我们的医疗案例演示了 DiD 如何评估远程医疗项目对再入院率的影响，R 代码提供了可操作的实现。处理前趋势检查、安慰剂检验等诊断手段进一步增强了结果的稳健性。在后续章节中，我们将探索断点回归（Regression Discontinuity）和合成控制法（Synthetic Controls）等高级方法，进一步扩充因果推断工具箱。

背景与解释

把 DiD 放进更长的因果方法谱系里看：它能处理「未测量的、不随时间变化的混杂」（通过差分消掉），这是它相对于倾向得分等方法的最大优势；但它处理不了「随时间变化且与处理相关的未测量混杂」，这是它与 RCT 的根本差距。因此报告 DiD 结果时，除了正文提到的诊断，还应尽量提供：处理组/对照组的构成描述、处理前多期趋势图、安慰剂检验与事件研究图、以及一套敏感性分析（如更换对照组、剔除政策同期事件、使用合成控制做对照）。这些材料共同构成审稿人判断「平行趋势是否可信」的证据链。
