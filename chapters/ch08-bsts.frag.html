8.1 引言

贝叶斯结构时间序列（Bayesian structural time series，BSTS）是一种强大的因果推断统计方法，适用于随机对照试验不可行、不合伦理或不切实际的场景。因此，它在评估人群层面的健康干预、政策变化和医学治疗方面极具价值。传统方法（如双重差分，difference-in-differences，DiD）假设处理组与对照组具有平行趋势（parallel trends）——这一条件在复杂的医疗数据中很少成立——而 BSTS 克服了这一局限。它能够对复杂的时间模式（如趋势与季节性）建模，并学习控制序列（control series）的最优数据驱动组合，以此构建一个合成的反事实（synthetic counterfactual）。

该方法的基础是将状态空间模型（state-space model）与贝叶斯推断相结合，从而实现稳健的不确定性量化。BSTS 不是给出因果效应的单一点估计，而是为反事实结局生成完整的后验分布（posterior distribution）。这种概率化方法为干预效应提供了可信区间（credible interval），天然而充分地将来自模型本身、模型参数以及预测过程的不确定性整合在一起。这种全景视角对于在医疗领域做出明智决策至关重要。

BSTS 通过将时间序列分解为若干不可观测的成分来建模，例如趋势成分、季节成分和回归变量的影响。对于一个从 \(t=1\) 观测到 \(T\) 的医疗结局 \(y\_t\)，若干预发生在 \(T\_0+1\) 时刻，模型的目标是预测反事实结局——即如果干预没有发生，\(T\_0\) 之后的 \(y\_t\) 会是什么样子。

核心模型被设定为一个状态空间模型，它由观测方程（observation equation）和状态方程（state equation）两部分组成。

  1. 观测方程：将观测数据 \(y\_t\) 与不可观测的状态向量 \(\\alpha\_t\) 联系起来。 \[y_t = Z_t^T \alpha_t + \epsilon_t, \quad \epsilon_t \sim \mathcal{N}(0, \sigma_t^2)\]
  2. 状态方程：描述状态向量 \(\\alpha\_t\) 如何随时间演化。 \[\alpha_{t+1} = T_t \alpha_t + R_t \eta_t, \quad \eta_t \sim \mathcal{N}(0, Q_t)\]

状态向量 \(\\alpha\_t\) 包含可解释的成分。医疗结局的典型分解可以是： \[y_t = \mu_t + \gamma_t + \beta^T x_t + \epsilon_t\] 其中：

  • \(\\mu\_t\) 是趋势成分（trend component），通常建模为局部线性趋势（local linear trend），它允许基线水平和增长速度随时间变化。 \[\mu_{t+1} = \mu_t + \delta_t + u_{\mu, t}\] \[\delta_{t+1} = \delta_t + u_{\delta, t}\]
  • \(\\gamma\_t\) 是季节成分（seasonal component），捕捉周期性模式（例如每周的医院入院周期或每年的流感季）。
  • \(\\beta^T x\_t\) 是回归成分（regression component），它对结局 \(y\_t\) 与一组不受干预影响的控制时间序列 \(x\_t\) 之间的同期关系进行建模。

于是，每个干预后时间点 \(t \> T\_0\) 的因果效应估计为观测结局与预测反事实值之差： \[\text{Effect}_t = y_t - \hat{y}_t^{\text{counterfactual}}\] 模型仅使用干预前时期（\(t \\le T\_0\)）的数据进行拟合，然后将反事实结局外推到干预后时期（\(t \> T\_0\)），以此估计因果影响。

背景与解释

合成控制法与政策评估：BSTS 在方法论谱系中的位置。医学研究者更熟悉的设计是"单一处理组的前后对比"或"双重差分"，而在计量经济学中，评估州/国家层面政策（如控烟立法、最低饮酒年龄、枪支管制）的经典工具是合成控制法（synthetic control method，SCM，Abadie 等提出）：用若干个未受干预的对照单位做加权平均，构造一个"合成对照组"，使其在干预前的轨迹与处理组高度吻合，再把干预后的差距当作政策效应。BSTS 可以理解为 SCM 的贝叶斯概率化扩展——它同样从多条控制序列学习最优组合来合成反事实，但额外提供了完整的后验分布（而不只是一个点效应）和更系统的变量筛选机制（尖峰-厚板先验）。对临床研究的启示是：当你面对的是"整个医院/整个地区实施了某项政策"而无法找到个体层面的随机化时，这类"聚合水平时间序列 + 合成对照"的思路往往比简单的 ITS 前后对比更有说服力。

状态空间模型的通俗理解。不必被公式吓倒：状态空间模型的思想与流行病学中的"潜变量"类似——真实世界中我们观测不到"疾病流行基线水平""季节波动强度"这些量，只能看到每月的就诊数；状态方程描述这些潜状态如何随时间演化，观测方程描述潜状态如何生成我们看到的数字。模型借助卡尔曼滤波式的递推在"看到新数据"与"更新对潜状态的信念"之间循环，MCMC 采样则把所有不确定性传播到最终的效应估计里。

8.1.0.1 控制变量的选择

BSTS 框架的一个关键特性，是能够为回归成分执行自动变量选择。这通常通过对回归系数 \(\\beta\_j\) 使用尖峰-厚板先验（spike-and-slab priors）来实现。每个系数的先验是两个分布的混合：一个"厚板"（slab，弥散的分布，如正态分布）和一个"尖峰"（spike，紧密集中于零的分布）。 \[\beta_j | \pi_j \sim (1 - \pi_j) \cdot \mathcal{N}(0, \tau^2) + \pi_j \cdot \delta_0\] 这里，\(\\pi\_j\) 是系数落在"尖峰"（即实际上为零）中的概率，\(\\delta\_0\) 是位于零点的点质量（point mass）。在模型拟合过程中（通过 MCMC），每个变量被纳入模型的后验概率会被估计出来，从而使模型能够从可能很大的控制变量集合中自动筛选出最相关的预测因子。

set.seed(12345)
n_months <- 60

# 创建时间索引
dates <- seq(from = as.Date("2020-01-01"), by = "month", length.out = n_months)

# 生成控制变量（候选预测因子）
unemployment_rate <- 6 + 2 * sin(2 * pi * time_idx / 12) + rnorm(n_months, 0, 0.5)
healthcare_access <- 80 + cumsum(rnorm(n_months, 0, 1))

# 一个强预测因子：相似地区的入院数

# -- 2. 拟合 BSTS 模型 --

# 修正：先定义 pre_period_data，再用于状态设定
pre_period_data <- full_data[pre_period, ]

# 定义模型结构（状态设定）
ss <- list()
# 现在可以安全地使用 pre_period_data$admissions
ss <- AddLocalLinearTrend(ss, y = pre_period_data$admissions)
ss <- AddSeasonal(ss, y = pre_period_data$admissions, nseasons = 12)

# 使用尖峰-厚板先验拟合 BSTS 模型（自动变量选择）
bsts_model <- bsts(admissions ~ .,
                   state.specification = ss,
                   data = pre_period_data,
                   niter = 3000,
                   ping = 0, # 关闭进度条
                   seed = 123)

# -- 3. 预测反事实并估计效应 --

# 用拟合好的模型预测干预后时期的结局
post_period_covariates <- full_data[post_period, -1] # 排除结局变量
predictions <- predict(bsts_model,
                       newdata = post_period_covariates,
                       horizon = length(post_period),
                       burn = 500) # 丢弃初始的 MCMC 样本

# 提取预测反事实均值与可信区间
pred_mean <- colMeans(predictions$distribution)
pred_lower <- apply(predictions$distribution, 2, quantile, 0.025)
pred_upper <- apply(predictions$distribution, 2, quantile, 0.975)

# 计算因果效应（观测值 - 预测值）
observed_post <- observed_admissions[post_period]
causal_effect <- observed_post - pred_mean
effect_lower <- observed_post - pred_upper # 效应下限 = 观测值 - 预测上限
effect_upper <- observed_post - pred_lower # 效应上限 = 观测值 - 预测下限

背景与解释

后验区间（credible interval）怎么读。上图是 BSTS 结果的标准呈现：黑线是实际观测，蓝色虚线是"假如没有加税"的反事实预测，浅蓝阴影是 95% 后验区间，红色竖线是干预时点。效应 = 两条线的纵向差距，而阴影的宽窄直接告诉你证据有多强。与频率学派的置信区间不同，贝叶斯可信区间的表述更符合临床直觉："给定数据和模型，真实效应有 95% 的概率落在这个范围内"。但它有两个重要前提——一是依赖先验设定（本例用默认先验，敏感性分析应换用合理先验重跑）；二是区间只反映统计不确定性，不包含模型设定错误带来的系统性偏差。医学报告中的惯例是：区间跨过 0 时，应如实表述为"未观察到统计学上可区分的效应"，而不是"没有效应"。

为什么要做安慰剂检验（placebo test）。时间序列因果分析最怕的是"模型把随机的波动当成了效应"。标准做法是安慰剂检验：把干预时点假移到干预前的某个时点重新拟合，如果那里也出现"显著效应"，说明模型的假阳性率太高，真实结论就不可信。多试几个假干预时点，效应估计的分布还能给出经验性的零分布参考。

分析显示，税收上调后与吸烟相关的住院入院显著减少。模型的变量选择自动将 neighboring_state_admissions 和 population_65plus 识别为结局的强预测因子，同时正确地给噪声变量 economic_index 分配了低重要性。

估计的效应随时间推移变得更加明显，这反映了行为变化的现实时间线——戒烟及其健康收益并非瞬间发生。因果效应的 95% 可信区间给出了一系列可能的影响范围，并恰当地考虑了来自季节模式、混杂变量和模型参数的不确定性。这种概率化输出使决策者能够以量化的置信水平评估干预的价值，超越了简单的点估计。

8.2.2 远程心理治疗项目评估

设想评估一个在 COVID-19 大流行期间上线的全州范围远程心理治疗（teletherapy）项目——当时传统心理治疗的可及性受到限制。BSTS 可以帮助评估该项目对心理健康相关急诊科（ED）就诊的影响，同时控制大流行本身、季节性心理健康模式（如冬季抑郁）和经济混乱带来的混杂效应。

下面的代码模拟了这一更复杂场景的数据。

# 心理健康干预模拟设置
set.seed(456)
n_weeks <- 104  # 两年的周度数据
intervention_week <- 52  # 项目一年后启动

# 生成心理健康急诊就诊模式
# 强年度季节模式（冬季高峰）
seasonal_mental <- 10 * sin(2 * pi * (1:n_weeks) / 52 - pi/4)
# 周内模式（如周一高峰）——修正后的公式
weekly_mental <- 3 * sin(2 * pi * (1:n_weeks) / 7)

# COVID-19 冲击（第 13 周突然发生，随后消退）
covid_impact <- ifelse((1:n_weeks) >= 13,
                      15 * exp(-0.02 * pmax(0, (1:n_weeks) - 13)), 0)

# 基线趋势
mental_baseline <- 40 + cumsum(rnorm(n_weeks, 0, 0.2))

# 控制变量
unemployment_weekly <- 8 + covid_impact * 0.3 + rnorm(n_weeks, 0, 0.5)
hospital_capacity <- 85 - covid_impact * 0.5 + rnorm(n_weeks, 0, 1)
control_region_ed <- mental_baseline * 0.9 + seasonal_mental * 0.8 +
                     covid_impact * 0.7 + rnorm(n_weeks, 0, 2)

# 远程治疗的真实效应（急诊就诊逐渐减少）
teletherapy_effect <- rep(0, n_weeks)
post_weeks <- (intervention_week + 1):n_weeks
for (i in 1:length(post_weeks)) {
  teletherapy_effect[intervention_week + i] <- -6 * (1 - exp(-0.1 * i)) + rnorm(1, 0, 0.3)
}

# 生成观测结局
mental_ed_visits <- mental_baseline + seasonal_mental + weekly_mental +
                   covid_impact + unemployment_weekly * 0.5 +
                   teletherapy_effect + rnorm(n_weeks, 0, 2)

cat("\nSimulation ready for teletherapy program evaluation.\n")
##
## Simulation ready for teletherapy program evaluation.

输出解读：模拟数据已就绪。注意数据里至少叠了四层时间结构：年度季节性（冬季抑郁高峰）、周内模式、第 13 周开始的疫情冲击（先冲高再指数消退），以及第 52 周启动的远程治疗效应。这正是 2020–2022 年真实心理健康服务的写照，也最能考验 BSTS 的本领——把项目效应从疫情冲击和季节性中分离出来。

cat("The true average effect of the program is a reduction of",
    round(abs(mean(teletherapy_effect[post_weeks])), 1), "ED visits per week.\n")
## The true average effect of the program is a reduction of 4.8 ED visits per week.

输出解读：模拟设定的真实效应是每周减少 4.8 次心理健康相关急诊就诊。原书在此未继续展示完整的 BSTS 拟合代码（流程与 8.2.1 完全一致：定义状态 → bsts() → predict() → 计算效应与区间），读者可自行复用上一节的模板，把月度数据换成周度、季节周期设为 52 周即可。

背景与解释

BSTS 在疫情与政策干预前后的应用：并发事件的陷阱。2020 年后的观察性研究几乎都面临同一个难题——干预与疫情等重大冲击在时间上重叠。BSTS 的识别假设要求控制序列"不受干预影响"，且控制变量与结局的关系随时间稳定。如果疫情同时冲击了处理地区和对照地区（例如全国性封锁），把疫情指标（如病例数、流动指数）作为回归控制变量显式纳入模型，往往能把疫情通道从项目效应中剥离；原书在结论中也承认，这类"重大并发事件"若不建模就会违反稳定性假设。更棘手的情形是"处理本身改变了疫情暴露"（如远程医疗减少了就诊途中的感染），此时无干扰假设被破坏，BSTS 的结论只能理解为"总体影响"而非纯粹的项目效应。医学研究者若遇到"多政策同时落地"（如DRG付费改革与带量采购同年实施），也应保持同样的警惕：时间序列设计能分离的是"某一时点的净变化"，无法自动区分并列政策的各自贡献。

对药物流行病学的延伸。同一思路可用于药品安全信号评估：例如某省 2021 年对某处方药发出限用令后，药物相关不良反应的报告数是否下降？可用全国其他省份的报告率（经过人口与疾病结构标准化）作为控制序列，构造"假如没有限用令"的反事实报告轨迹。前提同样是控制省份未受该限用令影响、报告体系一致。

8.2.3 医疗应用的实施指南

在医疗领域成功应用 BSTS，关键在于对数据和模型的精心准备。足够长的干预前时期至关重要——模型需要它来准确学习时间序列在变化发生之前的内在模式。对于月度数据，通常建议至少 24 至 36 个月的基线期，以完整捕捉年度季节性；而对于周度数据，100 个及以上的观测值能提供稳健的基础。

高质量控制变量的选择同样关键。核心原则是：选择那些与医疗结局相关、但本身不受干预影响的预测因子。合适的候选通常包括人口学指标（如年龄分布和保险覆盖率）、医疗可及性指标（如医生密度）、经济因素（如当地失业率），以及未接受干预的类似对照地区的结局数据。

最后，模型结构的设定必须反映医疗数据的复杂性。这通常需要考虑多个层次的季节性，例如由流感季或节假日驱动的年度模式，以及捕捉医院就诊星期几效应的周度周期。这些季节成分，再加上用于刻画人群健康渐变的灵活局部线性趋势，使模型能够构建精确而现实的反事实，从而估计干预的真实效应。

背景与解释

BSTS 与中断时间序列（ITS）的区别。中断时间序列（interrupted time series，ITS）是流行病学和药物流行病学中评估政策与质量改进项目（如手卫生规范、临床路径上线）的常用设计：用干预前后的同一队列/同一系统的结局数据，通过分段回归（segmented regression）同时估计"水平变化"（干预瞬间的跳变）和"斜率变化"（干预前后趋势的弯折）。ITS 的优点是简单、透明、可加入协变量调整，且只需要一条序列。BSTS 的优势在于：其一，不假设趋势是线性的，局部线性趋势允许基线水平和增速漂移；其二，可以利用多条对照序列合成反事实，从而部分替代 ITS 难以实现的"对照地区比较"；其三，效应形态自由——ITS 经典模型默认"立即且永久"的效应，而戒烟、减盐、早筛项目的效应往往是渐进的、先增强后衰减的，BSTS 用状态空间模型天然容纳这类形态；其四，输出的是完整的概率分布而非单一 p 值。实务上两者可以互补：ITS 适合序列较短、没有合适对照的场景；BSTS 适合有多个对照序列、序列较长的政策评估。报告时无论用哪种方法，都应画出原始序列 + 反事实/拟合线 + 区间，让读者自己判断。

8.3 结论

尽管功能强大，BSTS 分析的有效性仍依赖于几个需要仔细考量的关键假设。其中最重要的是无干扰假设（no interference assumption），即干预不会影响控制变量。这在公共卫生领域可能是个苛刻的条件——诸如对照地区的居民前往处理地区接受服务之类的溢出效应（spillover effects），会污染分析。此外，模型的结论可能对其内部设定（specification）敏感：趋势和季节成分的选择会影响由此产生的反事实，因此良好的做法是在不同但合理的模型结构下检验结果的稳健性。最后，BSTS 假设控制变量与结局之间的关系随时间保持稳定。像第二个例子中那样的重大并发事件（如大流行）可能违反这一假设，不过这类冲击通常可以通过把它们作为控制变量显式纳入模型来加以解释。

与几种传统的准实验方法相比，BSTS 具有显著优势。与双重差分（DiD）相比，它不要求严格的平行趋势假设，因为它可以灵活地对复杂的季节性和非线性趋势建模。BSTS 不依赖于单一的、预先指定的对照组，而是自动学习多个控制序列的最优加权组合。它还超越了经典的中断时间序列（ITS）分析——后者局限于简单线性趋势和即时、永久的效应——BSTS 能够刻画逐渐显现并随时间演化的影响。最后，BSTS 可以理解为合成控制法（SCM）的贝叶斯概率化扩展：它通过生成完整的后验可信区间提供更严谨的不确定性量化，并通过尖峰-厚板先验采用更稳定的自动控制变量选择方法。

贝叶斯结构时间序列为观察性时间序列数据的因果推断提供了一个稳健而灵活的框架。它对复杂现实模式建模、自动选择预测因子以及提供有原则的不确定性量化的能力，使其成为医疗与公共政策领域中循证评估的必备工具。成功的应用需要仔细斟酌数据质量、控制变量选择和模型设定，但回报是对干预真实影响更细致、更可靠的估计。

背景与解释

给医学研究者的选用清单。适合用 BSTS 的场景：结局是聚合水平的时间序列（医院月入院量、全州急诊量、药房处方量），处理是某一时点落地的政策/项目，且存在若干未受处理影响的对照地区。不适合的场景：个体水平数据（应回到倾向得分或双重机器学习）、干预前序列太短（不足两年的季节周期）、处理与对照之间存在明显干扰（如相邻省份患者互相流动）、处理时点不明确或逐步铺开（此时应考虑"随时间展开的处理"模型）。报告清单：明确干预时点与依据；说明状态成分与先验；给出 MCMC 设置（迭代数、燃化期）；附原始序列与反事实预测图；做安慰剂检验；对趋势/季节设定做敏感性分析；同时报告累积效应与逐期效应。最后提醒：BSTS 估计的是"处理地区相对于合成对照的净变化"，在撰写论文时建议使用 STROSA（时间序列因果推断报告规范）一类的清单组织结果，把统计估计与临床/政策意义分开陈述。
